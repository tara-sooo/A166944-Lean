## 1. Static pair relaxation and a common physical arrival-edge graph

Keep the actual original ensemble, H,T,N,B,u,ell,h=eta H (eta=ell^-1/4), actual terminal F_i and deficit, exact clock ledger and previous proved payments. Choose the entire backward relaxed static pair domain of XII, or any static true-birth sector S. For each ordered pair retain a single eligibility interval [a_ij,min(F_i,F_j)-h), possibly empty, where a_ij includes old individual maturity, birth age, fixed rank age and all applicable static masks. Half-integer rounding can be removed by enlarging endpoints O(1) at the old o(NT) cost; use a common exact real h and terminal upper bound. Drop slab-specific dynamic gates and induced endpoint ranks for this alternative, as in XII. Static failure gives empty interval; individual lower bounds may differ. Intervals symmetric in i,j in the original endpoint domain; if chosen static sector is directed, symmetrize by union as upper bound, or use symmetric graph counts from outset. The old uniform true birth age >>B is retained. Thus every eligible pair shares actual completed path with common pre-arrival, including the entire gain event covering x. We do not assume all original tags sharing an exit have the same arrival.

Use each actual completed ARRIVAL edge, keyed by (C,t), from prestate (t,C) to completed poststate (n,J), with selected p, J=C+p-1. Deterministic MIN uniquely determines edge. Distinct arrival states at same C may share a completed exit (and truly meet within waits before the exit). Until that exit keep them distinct. For each tag on this edge its interpolated ordinary deficit d_e(x) is identical, continuous to both actual end states, with slope in [-1,5]. All eligible pairs share their arrival edge, since their actual first birth precedes their source by >>B. Distinct arrivals converging at a completed exit have true birth at horizon at most B earlier than that exit (if they already met inside waits at common C, C=J-g; otherwise actual first meeting at exit). They therefore cannot be eligible immediately at the join. A root injection has ordinary deficit6 and singleton history, no pair active at insertion. Original terminal tags do not continue. The projected gain direction is strictly increasing.

Define virtual expiry E_i=F_i-h. Use only actual life [C0_i,E_i) if nonempty, and on each edge define b(x)=number of its full original members with E_i>x. This is a restriction of actual life, not extension. Within edge b is nonincreasing. Every eligible pair belongs to that population. b(x)<= original full physical exit population used in V/VI/XII. Let A(x)=number of eligible ORDERED distinct pairs on that edge, after static relaxation, and a(x)=A(x)/b(x), zero if b=0. A<=b(b-1). We deliberately drop b0 in this upper bound: 1/b >=1/max(b0,b_exit); the common denominator avoids double-counting terminal charges among different birth anchors. This is potentially looser than original denominator or anchor sector, but retains all actual arrivals through the graph and gives a different exact global formula. The nonnegative clock upper follows by the entire-integral unfreezing in XII, then denominator enlargement:
    W_B^S <= V_S^graph + o(NT),    V_S^graph = sum_edges integral a(x) omega_e(x) dx,
    U_S^graph = sum_edges integral a(x) dx.
No double count of same pair across overlapping birth rays or slabs. If choose full domain, omit superscript S. The new relaxed domain can contain extra pairs, so this is not equality of exact backward ledger.

## 2. Exact signed global balance

Consider the step function a(x) on an edge. At eligibility start of a pair, A increases with fixed b; call its nonnegative increment activation. At virtual expiry, first remove retiring vertices and their incident pairs, THEN activate any new pairs among survivors at same coordinate. Define R as sum of d times the signed DROP in a due to virtual retirements; this drop need not be nonnegative for an arbitrary sparse graph (removing an isolated vertex raises a). At edge endpoint, perform virtual retirements before merger, and count pair activation after merger. At true completed poststate v, all incoming surviving edge cohorts have common d_v and disjoint tag sets; outgoing b=sum b_j plus possible root injection (provided virtual life nonempty). New cross-pairs cannot be eligible yet by age >>B. Thus outgoing A before activation is sum A_j. Merger dilution drop is
    D_v = sum_j A_j/b_j - (sum_j A_j)/b >=0.
Here zero cohorts omitted; a singleton root injection has A=0. Count root insertion at an existing poststate as a possible dilution. Terminal-only vertices have no surviving flow and all their drops counted as retirements. Define M=sum_v d_v D_v>=0, C_act=sum d times activation increments>=0. No initial boundary term from new singleton root pair count zero. Sum exact edge integration by parts with slope identity 2omega=1+d'. All intermediate endpoint values cancel except their changes, so
    2 V_S^graph = U_S^graph + M + R - C_act.               (1)
This includes arbitrary static pair-specific lower ages, not just factorized masks. In particular the merge term is positive because merging dilutes existing pair density; the activation term has opposite sign. Their difference is signed, and one must not drop activation when claiming a cancellation. The old anchor survival debit had a different sign decomposition because different denominators per birth. Formula (1) counts the same actual graph weight only once across all birth sectors if full domain used.

## 3. Retirement surplus and cancellation of the total terminal deficit

At one virtual retirement event on an edge, let pre mass b=s+k with k retiring, s surviving. Let A_s be ordered pair count among survivors BEFORE any activation, C be unordered cross-edge count (one retiring, one surviving), A_k ordered pairs internal to retiring set. Then before A=A_s+2C+A_k. With s>0 the signed drop in a is
    delta = (2C+A_k - k A_s/s)/b.
Write missing ordered internal pair count m_k=k(k-1)-A_k, missing cross count m_c=ks-C (both nonnegative), a_s=A_s/s. EXACTLY
    delta - k = [k(s-1-a_s)-2m_c-m_k]/b.                 (2)
If s=0, delta=A_k/k<=k-1, excess delta-k<=-1. Hence
    delta - k <= (k/b)(s-a_s)                            (3)
(with zero RHS for s=0). This bounds positive retirement surplus by uncovered survivor pair mass, not by the absolute terminal deficit times 2. Complete surviving graph (a_s=s-1) has nonpositive surplus, as does complete entire graph (exactly zero surplus if s>0). Sparse graph can genuinely have positive surplus: for star with one retiring center and b=10, delta-k=.8. Do not assert terminal coefficient <=1 pointwise. Also exact missing cross terms in (2) can be retained instead of (3). Put
    Z_virtual = sum_(virtual active tags) d_i(E_i),
    S_ret = sum_(retirements) d_e(x)(delta-k),
    S_ret^up = sum_(retirements,s>0) d_e(x) k(s-a_s)/b.
Then R=Z_virtual+S_ret, S_ret<=S_ret^up. S_ret may be negative. Since d_i' >=-1, d_i(E_i)<=d_i(F_i)+h. Tags with empty virtual life contribute nothing to Z_virtual, actual deficits nonnegative; hence Z_virtual<=Z_all+Nh=Z_all+o(NT). Lower inequality not needed. Retain exact terminal deficit on left from XII. For full graph route under finite twins,
    NT-o(NT) <= U^graph + M + S_ret - C_act + 2c_a(D_l+D_h)
                 + (Z_virtual-Z_all)
              <= U^graph + M + S_ret - C_act + 2c_a(D_l+D_h)+o(NT).
The sufficient criterion becomes
    liminf [U^graph + M + S_ret - C_act + 6(D_l+D_h)]/(NT)<1. (4)
One can replace S_ret by S_ret^up. More exactly retain Z_virtual-Z_all in (4), which could be negative. This is a global terminal cancellation, not the invalid E_S<=Z_all assertion of XII. It leaves a merger-activation balance and retirement surplus, which still need a strict upper. Full backward domain is required for this full cancellation; for static sector S alone the virtual terminal term still counts ALL virtual tags if using (2), so do not sum multiple sector versions with one Z_all. For partial sector, use (1) with its own R and complementary original signed bound; choose minimum with XII. No assertion (4) dominates all older sufficient criteria.

Under finite twins total virtual gain sum_i (F_i-h-C0_i)_+=NT-o(NT) (overshoot O(NB)); U^graph<=this. Thus (4) equivalently asks for a strictly positive normalized gap between uncovered virtual gained length and M+S_ret-C_act+6D, up to o(NT). This locates the remaining obstacle in graph changes and forward defect, rather than raw terminal drift. A graph with all pairs eligible immediately at merges violates the no-cross activation assumption, but can include the new cross count as activation at that same vertex; it does not give strict contraction merely by complete coverage.

This follows from direct (5) with G+p<=2G and log(2+G/p)>>epsilon u. The common-ray blocks can be IX-X regular tiles (M0=X^(1-o(1))) or any such long disjoint blocks along a tag. If a sufficiently long common birth continuation has a chosen population exceeding respective fractions by a fixed constant, the weighted actual twin certificate is positive, with q>=A_3. This imports a direct local twin forcing condition on sparse giant merger rays; no proof such high-gain narrow alphabets occur. For truly flat runs direct (11) applies without twin assumption, including other k with finite support. Do not apply these to an arbitrary positive level window just because its relative deficit is narrow: width <2A_3 and small alphabet are actual extra restrictions.
