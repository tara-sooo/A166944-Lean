## 2. Global disjoint retirement lemma

More generally take any integer thresholds 0<=m<b. Use light projected horizons with full population <=m, large true completed exit slots of size >=b. For every tag that visits a light horizon after a large slot, consider the FIRST subsequent light arrival following that large slot. Record the actual true arrival vertex V=(t,C), including terminal arrivals. Let R be the set of distinct such V across original tags and large slots, and for each V choose ONE actual witnessing large slot L_V with its full population G_V. The witnessed common deterministic continuation from L_V to V has no intermediate light horizon. Every tag in G_V either visits V or stops strictly before it. (All execute the same completed departure at L_V; terminal snapshots are included.) At most m visit V. Thus the set Q_V of tags in G_V that stop strictly before V has size >=b-m.

Claim: Q_V for distinct V are pairwise disjoint. If a tag i were in Q_V and Q_W, it actually executed both witnessing large slots on its one true trajectory before its terminal. Order them along this trajectory, say L_V first. Both lie strictly before V: i stops before V. The continuation from L_V to V on its witnessing tag must agree with i through L_W by determinism. Since there is no light between L_V and V, there is none from L_W to V either. The first-light continuation from L_W is therefore V, so W=V. This argument compares only actually witnessed continuations; it does not require defining an extended trajectory of the stopped tag i. Equal large slots also imply equal first light. Hence
    (b-m)|R| <= sum_(V in R)|Q_V| <= N.                 (1)
Every original tagged first-light return arrival is one of these vertices; multiple preceding large slots giving the same arrival are counted once per tag, and a tag visits a true vertex at most once. Each V has <=m original visitors, so the total number of tagged return arrivals is <=m |R| <= N m/(b-m). Let Bad be the original tags making at least one such return, even if later or earlier charges do not use that large slot. Then
    |Bad| <= N m/(b-m).                                (2)
No bound on the number of light visits before large slots is asserted. The distinction between projected-light and physical-large is essential: projected-large populations may split into many true paths, so this lemma is not valid with a merely projected-large witness. It is valid without all roots reaching T, without synchronized terminal gains, and with mergers between witness paths.

With (m,b)=(m_light,b_big), Bad=o(N). Each original tag has summed row+column clock involvement in BOTH original transports <=2 c_a(H+P) on any grid. Pay all surviving charges with either original source role in Bad, including charges before its return. Total <=2 c_a(H+P_max)|Bad|=o(NT). Use old exact joint kernel and masks; this counts each involved charge at most twice for an upper bound, not a new weighting. All actual backward source participants have executed a large slot at source, so none can later visit a light horizon. The same conclusion for forward participants is NOT automatic from the phase-class mass lower bound alone; only the Bad-tag payment applies to all forward roles.

## 3. Global final nonmoving tails and two endpoint strips

Root starts are moving. Any original tag that is nonmoving at an actual source and has no future light visit is nonmoving at its terminal and has a unique globally final expiry jump f_i, the last moving-to-nonmoving transition. Write J_i its actual posthorizon, F_i its actual terminal horizon. The entire tail [J_i,F_i] in recorded gain coordinates is nonmoving. All surviving backward source participants satisfy these properties by section 2 and the old source-moving masks. Thus the last source-clipped expiry equals this global expiry; no reset occurs later in the original history. For all original tags with terminal nonmoving status, final expiry is well-defined by the recurrence; other tags have no final tail for this argument. A tag with a last expiry but terminal moving status must NOT be included in a final-tail capacity.

Choose h=eta H, eta=ell^(-1/4). Pay every remaining backward atom with either participant i having K<J_i+h or K>F_i-h. For one tag and grid the first strip and final strip have each at most h/P+1 boundary atoms (strict crossing atoms only), and per-tag either-role capacity <=2 c_a P. Consequently total clock <=4 c_a N(h+P_max)=o(NT). All new masks are applied sequentially to the frozen exact charges. No full history length needs to be charged for each earlier expiry. Every remaining backward source atom satisfies
    J_i+h <= K <= F_i-h
for BOTH original participants i. In particular their final nonmoving tails have length >=2h, and the eligible part of their lifetime is at least h away from final expiry and terminal. This strengthens the previous mixed expiry age D_s/3 to h (h/D_s->infinity). It is a gain-coordinate condition on K, not on tick time or the birth state. It also applies to both-nonmoving births. Forward endpoint strip claims are not needed, and forward residual unchanged except Bad-tag payment.

## 4. Global mixed-expiry envelope with no repeated fresh lifetimes

For each actual expiry slot f=(C_f,p,v,J_f), define E_f^* as original non-Bad tags whose global final expiry is f and whose terminal is nonmoving. Define O_f^* as original non-Bad tags executing this same f whose global final expiry has occurred strictly BEFORE f, whose terminal is nonmoving, and which remain nonmoving from that expiry through their terminal. These latter conditions exclude any subsequent moving reset; they hold automatically after the last expiry when terminal nonmoving (a reset would need another expiry). E_f^*,O_f^* are subsets of the old E_f,O_f of 9947338. Each fresh tag belongs to at most one E_f^*, so sum_f |E_f^*|<=N. The old sets E_f could contain the same tag at many earlier expiry events; this new disjointness is global, not just within one source cohort.

For each K>=J_f+h let
    e_f(K)=# {i in E_f^*: F_i>=K+h},
    o_f(K)=# {j in O_f^*: J_j+h<=K<=F_j-h}.
A mixed surviving pair of 9947338 reindexed at the moving participant's expiry f is contained in these two sets at its source K. Indeed there was no common light between birth and source, neither source participant is moving, and no future light follows the massive source. Thus the moving member's source-clipped expiry is its global final expiry, and the other member's global expiry is strictly earlier. Their trajectories agree from f to K. No later first meeting can be substituted. At a fixed f and K at most one actual source slot occurs by determinism. Actual involved counts x_E<=e_f(K), x_O<=o_f(K), x_E+x_O<=b with b>=b_big. Original ordered-pair cap gives
    B_mixed,final <= 2 c_a mean_P [
      P sum_f sum_(K multiple P, J_f+h<=K<J_f+H)
          e_f(K)o_f(K)/max(b_big,e_f(K)+o_f(K)) ].     (3)
Use monotonicity of xy/max(b_big,x+y) in each argument as before. This is a simultaneous global upper bound, not a sum assuming independent charge keys. The lower endpoint of the K sum is valid because of the strip payment. One can further restrict to old admissible birth/expiry keys and actual source predicates. The functions need not both be monotone (the old side has an eligibility lower endpoint), so use discrete sums, not an unproved monotone Riemann estimate.

As each summand <=e_f(K) and each fresh tag appears in a UNIQUE f, the entire right side of (3) is <=
    2 c_a [ sum_(i with final tail, non-Bad) (F_i-J_i-2h)_+ + N P_max ].  (4)
The P overhead is from counting inclusive endpoints; if tail length <2h it can be dropped for that tag. This is a uniform aggregate upper bound on the sum of the new relaxed lifetime capacities, even if old-side sets overlap greatly between different f. It is <=2 c_a N(H+P_max). The essential improvement is one final lifespan per tag instead of one per arbitrary moving expiry. It does not make the bound o(NT) by itself.

There is also an exact shared-denominator bound at one original source G (size b), independent of the old eligibility masks. Let n_* count its non-Bad final-tail members satisfying the two endpoint tests. Partition those by global expiry key f, with count e_f^G. Every actual mixed pair lies between different expiry groups, and is assigned to the later expiry in actual time. Equal expiry times at distinct physical states cannot be mixed because both members would have to execute the same expiry jump. Hence all mixed ordered pairs at this source have raw clock <=
    c_a P [n_*²-sum_f (e_f^G)²]/b.
This counts every pair at most once for each orientation and may be smaller than summing independent two-role capacities. Actual first-meeting predicates only reduce it. For ALL backward surviving pairs the row sum gives <=c_a P n_* (and the per-pair cap gives c_a P n_*²/b); summing and using unique final tails yields
    B_all,new <= c_a [ sum_i (F_i-J_i-2h)_+ + N P_max ].   (5)
In (5) sum over non-Bad final-tail tags. This is an unconditional direct upper bound on the whole backward component in terms of a single scalar residence sum, including both-nonmoving births. It is not a bound for the forward component, and may be larger than the exact old weighted tree envelope; take minima of valid bounds. In particular a sufficient test for the combined route is liminf [3 R_final +3(D_l,new+D_h,new)]/(NT)<1/2 where R_final=sum_i (F_i-J_i-2h)_+. No proof of this test, nor of R_final being a sufficiently small fraction of NT. The age strip does not create a constant margin, since eta->0. Equation (5) uses only one row contribution per tag, not the factor 2 from bounding mixed pair involvement separately.
