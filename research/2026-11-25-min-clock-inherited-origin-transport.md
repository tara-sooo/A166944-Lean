## 2. Persistent-origin partner disjointness and actual target gain

Fix an earlier-origin O and lambda. For each actual target A reached by outgoing positive edges of O, let R_(O,A) be its distinct participating earlier-origin sources and L_(O,A) the distinct later-origin opposite sources on those actual edges. Put n_(O,A)=|R_(O,A)|, h_(O,A)=|L_(O,A)|. Let L_O be their union over A and H_O=|L_O|. All R_(O,A) are subsets of the same a_O sources; these subsets can overlap and need not have equal sizes.

The L_(O,A) are PAIRWISE DISJOINT across distinct A for this fixed O. Proof: all right-origin sources share their true state at O, hence their deterministic continuation agrees until the first relevant original stop. For every actual target A this trajectory stays at or above lambda from O through first contact and through the completed target wait. The latest actual target by its departure time is witnessed by some right source reaching it in its original path; that path also traverses every earlier target slot. Indeed each earlier witness starts from the same state O, has the same common suffix for the time in question, and the latest witness continues at least as far. Suppose a left source M were a left endpoint at an earlier target and again at a later target of O. It shares the reference suffix from the earlier contact onward as far as it continues. It is actually present at the later target by the alleged second edge, so it shares the persistent above-lambda continuation up to there. It cannot perform a new stationary upcross of lambda there, contradiction. This argument does not require that the SAME right source was an endpoint in both edges, nor assume all class members survive to every later target. Both upcrosses are actual and old paths are not extended for charging. Therefore
    H_O = sum_A h_(O,A).
In particular each distinct opposite source counts once across ALL targets for that O and lambda. The outgoing total W_O has bound
    W_O <= U0 sum_A n_(O,A) h_(O,A) <= U0 a_O H_O.       (2)
The last inequality would also follow by a distinct actual pair bound; the disjointness gives the more precise sum identity useful for degree and gain estimates.

The same latest actual donor path proves

At a fixed lambda each target A is a distinct completed slot, r_A is its minimum eligible prime, and the actual selected outgoing gain pays r_A<=1.5(p_A-1). If target minimum r>=R is imposed, the number of targets <=O(B/R). Without it the earlier small-drift filter r>ell/4 gives only O(B/ell). This is a count of actual distinct targets, not a bound on incoming origin classes or source multiplicities. A target can have multiple earlier origins (the audit measures this). The latest actual witness exists even with staggered original cutoffs; no extra reference length or independent continuation is needed.
