## 3. CRT spacing cancels the phase-class loss for small focal labels

For two slots in the SAME class at fixed C,q the lag is a multiple of
    lcm(2q,L0)=q L0=2Aq.
Thus within radius R the number of possible slots is at most floor(R/(Aq))+1, rather than floor(R/q)+1. This sharper spacing is essential. Define
    R_e=16 max(P_max,p_e),
    Z_e=max(P_max,L0 p_e),
    n_phase_cut(e)=H/(256 Z_e u ell³).
For every good witness q, either q=p_e (self), or q<=P_j/a<=P_max/a. Since A<=ell/2<<a, A q<=Z_e in either case. Also R_e<=16 Z_e. When n_e<=n_phase_cut, use b_v<=2n_e to obtain
    (floor(R_e/(Aq))+1)b_v
       <= 2 n_e (R_e+Aq)/(Aq)
       <= 34H/(256 A q u ell³)
       < theta n_c/4,
since n_c>H/(Aq u ell²). The rank lower bound now leaves >theta n_c/2 far smaller-or-equal-mass partners of the SAME class. Subtracting unstable class partners leaves
    f_phase_stable(C,q,v;R_e)>3 theta n_c/8
                           >3H/(8 A q u ell³).            (1)
The uniform bound also holds for the local radius R_P(q)=16 max(P,q)<=R_e. All partner departures have nonzero lag divisible by q L0, and the anchor-strand representation from f2a7cf2 applies unchanged to their stable representatives. For small focal p_e<=P_max/L0, the new physical cutoff equals the previous n_cut(e)=H/(256 max(P_max,p_e)u ell³), exactly. In particular it is unchanged throughout the nonself focal sector p_e<=P_max/a, since a>>L0. Without exploiting the new exit spacing, the phase-class subdivision would unnecessarily lose a factor A in the physical cutoff. The partner tag-count lower bound does lose a factor A, and for very large self labels the physical cutoff can shrink by L0. This is a tradeoff, not a claim that the original full far energy is upper-bounded by the restricted phase energy.

Define the normalized phase-stable energy on each grid by

       (floor(R_P(q)/(Aq))+1)b_v <= theta n_c/2)
                 b_v f_phase_stable(C,q,v;R_P(q))/n_c.
Use original counts, with zero terms for empty classes. This has unconditional upper bound N(H+P), as the partner fraction is <=1 and class masses partition n. Removal of unstable partners changes the corresponding energy before stability cleaning by <=Q_bad(P): for each partner the sum of focal coefficients b_v/n_c in its class is <=1. where W_massive_phase includes the residual clock with n_e>n_phase_cut. It follows by the original deficit identity and the o(NT) masks. ## 4. Common arrivals, primitive projected returns and strict one-edge skew

Consider two distinct stable physical anchor strands from f2a7cf2. For any common prehorizon C, let their actual arrival times be t_A(C),t_B(C), signed lag Delta(C)=t_B(C)-t_A(C). Include common postdeparture horizons, since each is a recorded next arrival or original terminal. If C<D are common horizons, the two elapsed waits over [C,D] are each in [0,3(D-C)], so
    |Delta(D)-Delta(C)|<=3(D-C).                         (3)
Call C,D a primitive projected return if neither strand has an intermediate recorded horizon common to both. No requirement of identical selected labels on the two paths. At any phase-matched common arrival (Delta divisible by L0), the first translation defect before a later common arrival must have at least one label >y0, by exact MIN translation. A terminal is not a defect. All claims concern completed events within the two recorded intervals.

NEW one-edge return lemma: suppose path A makes ONE completed jump p from C to D=C+p-1. Path B makes m>=2 completed jumps to the same D, with first label q. Then p>q because all gains positive. If 2q divides Delta(C), the first B candidate at its own departure translates to an eligible candidate with the same positive wait on A. Since A chooses p>q in lexicographic MIN (next tick, label), its wait w_A is STRICTLY less than B's first wait w_B1: a tie would choose q, not p. This comparison is within the original cutoff of A because the candidate would otherwise not challenge its completed earlier selection. More explicitly, if w_B1<=w_A the translated candidate lies before or at A's actual completed tick, hence is eligible under the cutoff. Since waits are integers and the remaining m-1 B events each have wait>=1,
    Delta(D)-Delta(C)=sum_(B interval)w_B-w_A >= m.       (4)
If B is the single-jump path the sign reverses. In particular equal endpoint lags are IMPOSSIBLE in a one-edge vs multiple-edge return if the first label of the multiple-edge side has period dividing the initial lag. This statement is valid without any phase-wheel assumption; the first label can be large but periodic. The interval is necessarily primitive when one path uses a single jump. The inequality is independent of cohort masses. It improves a non-strict first-wait comparison which would yield only m-1. No assertion of (4) when the first multi-side label is nonperiodic.

There is an additional local exclusion when both endpoint arrivals match phase modulo L0. If D-C<L0/3, (3) and divisibility of both endpoint lags imply Delta(D)=Delta(C). If exactly one jump per side then they have the same label, same wait, and are an unchanged translated edge. If one edge vs multiple then (4) forces 2q NOT dividing Delta(C); in particular q>y0, and single label p>q>y0. This eliminates all short same-phase one-edge diamonds with a small first label on the multi side. The obstruction applies even if p is not a divisor of the starting lag. A multi-edge vs multi-edge return can have lag restored after a defect, and is not eliminated.

## 5. Per-pair quantized renewal bounds

On a fixed pair of distinct original strands within a common horizon interval of length L, list any increasing sequence of common arrival horizons with lag divisible by L0 (e.g. the posthorizons of shared same-phase witness departures). Consecutive intervals are disjoint in gain on each strand. By (3), the number with different endpoint lag is <=3L/L0; each change is a nonzero integer multiple of L0. If the endpoint lags are the same but the interval is not an unchanged translated path, at its first actual defect at least one selected label is >y0. Assign one such event in the interval, on one of the two sides. Because intervals are disjoint, these assignments are injective as tagged events on the two sides. Consequently the number of such intervals is <=2L/(y0-1). This also bounds the number of nontranslated intervals of either type if desired, since all nontranslated intervals start at phase match. The translated case still obeys the radical barrier of f2a7cf2. The new bounds count repeated intervals for ONE pair, not across arbitrary different pairs. In particular an unchanged lag at the endpoints does not prove no defect; the first-defect payment in this paragraph explicitly uses the actual intervening paths.

For a repeated stable partner among good nonself witnesses, the shared posthorizons lie in the O(P_max) focal span with lag sign constant as in f2a7cf2. They are phase matched by construction. The above bounds partition such a pair's repeated returns into translated segments, quantized lag changes (minimum gain L0/3), and lag-restoring defects requiring a label >y0. Short one-edge returns with periodic initial multi-side label are further excluded by (4). This does NOT force the pair's same-phase common witness set to be consecutive in the full shared-arrival list. If intervening unmatched common arrivals occur, the quantized bounds apply to the larger consecutive phase-matched intervals, while the one-edge lemma applies only to the specified single-vs-multi actual intervals. No multiplication of per-pair bounds by the number of pairs has a proved linear capacity estimate. Partner sets can still change across witnesses, and multi-edge lag-restoring defects remain. No upper bound establishing (2); no claim of complete proof or Lean compilation.
