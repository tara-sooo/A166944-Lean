## 1. A hard reserve with unit retirement bound

Keep XV's actual individually eligible intervals E_i=[a_i,F_i-h), static age connectivity components, and two fixed color partitions (historical packet, first actual large vertex), with all classes <=P=dmax L_old=o(b0). On each component's eligible actual set S, n=|S|, define m(S)=max over both partitions and their classes of the number of members of S in that class, zero for empty S. Let R be the old integer regularizer round sqrt(P b0), or any positive integer R>=old regularizer with R=o(b0). Put
    f_h(S)=(n-R-m(S))_+.
For disjoint sets m(S union T)<=m(S)+m(T), and under insertion m increases by either 0 or 1. Consequently f_h is monotone, changes by 0 or 1 on inserting one member, and superadditive. For superadditivity if both terms positive use the subadditivity and the single R charge; if only one positive use monotonicity; if neither positive trivial. Iteration gives 0<=f_h(S)-f_h(S minus K)<=|K|. Unlike XV, no positive retirement surplus is possible at any size.

For each color c with squared counts S2_c, m(S)>=max count for c and S2_c<=n m(S). The XV smooth weight satisfies
    (n²-S2_c)/(n+R) >= n-R-m(S).
It is nonnegative. Hence f_h<=min_c f_c for identical R and population. The new age weight a_h=sum over actual component groups f_h(S_j) is pointwise <=XV's a_age, even for arbitrary overlaps of the two color partitions. Increasing R further reduces a_h. This is an actual nested upper bound UP TO the changed o(NT) error; not a pointwise upper on exact pair weight without error.

For original unfreezed denominator d0=max(b0,b_exit)>=max(b0,n), A_old<=n², K=R+P. Since f_h>=(n-K)_+, for every n>=0,
    n²/d0 <= (n-K)_+ + K n/b0 <= f_h+K n/b0.       (1)
If n<=K and n<=b0 use n²/b0<=Kn/b0; if K<n<=b0 use (n-K)(1-n/b0)>=0; if n>b0 use n²/d0<=n and K n/b0>=K. Thus the old pair upper integral remains valid, W_B<=V_h+o(NT), V_h=int a_h omega, U_h=int a_h, denominator error <=3(K/b0)NH=o(NT). Sum component groups using actual eligible n, no factor number of groups. Can choose a larger reserve R=floor(b0/ell) eventually (P=o(b0/ell²)), still o(b0) and improves upper further; this changes the o(NT) error and does not yield a fixed margin alone. The age connectivity and actual eligibility masks stay unchanged; no new abstract edge for an ineligible pair.

## 2. Exact graph balance with a fourth nonnegative debit

Use the actual arrival-edge graph of XV, retire first, physical merge with left age partition, abstract coarsening, then insert individually eligible starts. Same continuous deficit d, slope 2omega-1. Define C_merge,C_age,C_start as d times weight increments at these respective operations, all nonnegative. At retirement of k actual eligible members let delta be the drop in a_h, then 0<=delta<=k. Define the NEW nonnegative C_ret=sum d(k-delta). Each eligible member retires once at its virtual expiry. Z_elig=sum eligible expiry deficits; Z_not=sum actual terminal deficits of empty E_i. Now the exact identity is
    2V_h=U_h-C_merge-C_age-C_start-C_ret+Z_elig.      (2)
No o(NT) estimate of positive retirement surplus needed. Z_elig+Z_not<=Z_all+Nh still. Combining original actual total clock, old forward bound and (1), under finite twins:
    NT-o(NT)<=U_h-C_merge-C_age-C_start-C_ret-Z_not
                                   +2c_a(D_l+D_h).
Sufficient strict liminf of [U_h-C_merge-C_age-C_start-C_ret-Z_not+6(D_l+D_h)]/(NT)<1. Retain exact Z_elig+Z_not-Z_all for sharper finite comparison. Old credits cannot be added to these. All C computed on SAME hard graph. Asymptotic denominator error still needed. This proves the sign of retirement exactly and improves the raw backward upper V_h<=V_age, not by a claimed fixed fraction.

## 3. Uncovered mass as integral flow and exact missing-clock budget

At any actual edge position let n_total be total individually eligible tags there, a_h aggregate hard weight. Set q=n_total-a_h. Within each age component q(S)=min(n,R+m(S)); in particular q>=min(n,R) per group. Define Q_h=int q=L_ind-U_h and W_miss=int q omega. At any actual physical merge, n is conserved, q drops by the coverage increment; at abstract age coarsening same. At a single eligible start, coverage increases by delta=0 or1, hence q increases by 1-delta; at retirement q drops by k-delta. Thus q is a nonnegative INTEGER flow on the subdivided actual arrival-edge graph, generated only at actual eligible starts, consumed at physical merges, abstract coarsenings or retirements. It admits a path decomposition by carrying integer tokens forward and choosing any tokens for each required sink; at merge concatenate incoming token lists. One may refine by age groups (coarsening joins groups); no need for a token to be permanently identified with the same original root after physical merge. Every path follows actual edges with eligible members, no continuation through an empty edge, and its d is continuous at physical joins. A start with delta=1 may be included as a zero-length token immediately consumed at the start. Exactly one token (possibly zero-length) per nonempty E_i. The integral Q_h equals sum of actual token gained lengths. Along a token path from x=a to x=b, 
    (b-a)+d(b)=d(a)+2 integral_path omega.
This is exact, independent of chosen token matching. With C=C_merge+C_age+C_start+C_ret and Z_start=sum_{nonempty E_i} d_i(a_i), total sink deficits=C, hence
    Q_h+C = Z_start + 2 W_miss.                    (3)
In particular all eligible starts' deficits are paid, including sparse starts that had no individual start debit. This is a combined lower bound on Q_h+C, not a lower bound on C_start alone. Also (3) follows by subtracting (2) from exact eligible clock balance; the token decomposition gives local origin/sink and length information rather than a new independent credit.

For each nonempty E_i, let W_pre be actual interpolated prefix wait before a_i; let W_empty be total actual waits of empty E_i, W_tail actual waits after virtual expiry of nonempty E_i. Then exact full missing-clock identity
    W_all-V_h = W_empty+W_pre+W_tail+W_miss.        (4)
All terms nonnegative; W_tail<=3Nh. For a_i prefix age l_i=a_i-C0_i, l_i+d_i(a_i)=6+2 prefix wait. Hence
    (G_all-L_ind)+Q_h+C+Z_not
      =2(W_empty+W_pre+W_miss)+6N
          + sum_{nonempty E_i} (F_i-e_i),
where e_i=F_i-h (last sum = h times nonempty count). This follows by using G_i+df_i=2W_i+6 for empty E_i and l_i+d(a_i) for others. In finite twins G_all=NT+O(NB), so the combined debit is the missing actual clock outside the backward envelope, up to o(NT), not five independent supplies. This prevents claiming a proof by adding (3) or the prefix debit once again to the old sufficient criterion. The exact original partition implies under finite twins (indeed for full residual after valid payments)
    W_empty+W_pre+W_miss <= c_a(D_l+D_h)+o(NT).
To contradict finite twins it suffices to prove a uniform reverse strict gap at scale NT. This identifies the clock measure to compare with exact forward source charges. Merely nonnegative q or bounded token length does not establish it. A concrete next task is to show forward defect supply is smaller than this uncovered-clock budget on the original joint source kernel, with its phase word fraction and actual assignments, rather than compare forward energy to a sum of unrelated gained-length bounds.

For any fixed deficit level d0>=0, token costs with start d>=d0 already contribute >=d0 each to Q_h+C by d'>=-1. For low starts that flow through group sizes <=R, coverage is identically zero there, so every gained interval in such groups contributes its full eligible population to q and actual waits to W_miss. More generally Q_h>=sum int min(n_j,R), W_miss>=sum int min(n_j,R) omega. These are explicit simultaneous early-age and small-component bounds, not extra quantities to add to (3). Token switching cannot justify original per-tag age or rank after a merge.

## 4. Direct growing multipliers and uncapped zero-stratum chains

Direct c4ef87a replaces the fixed multiplier cap by M<=X^(a-epsilon) for selected polynomial labels p>=X^a, a>1/14. Under its close conditions (E<=B_cut, |v|<=A_cut, A_cut+5B_cut<=(T_label-1)/2), actual ending gain is O(X M log(2M)(B_cut+1)(A_cut+1)/u²), uniform in cap, with automatic long successor. On one original ray H~X/u^.25, if M log(2M)(B_cut+1)(A_cut+1)=o(u^(7/4)) this is o(H); e.g. M=floor(u^.5), A_cut=B_cut=floor(u^.5). Aggregate over actual tags ONCE (not each short tile), and graph a_h<=n permits the same selected focal wait deletion by w<=3g with actual eligible transitions. On a block G comparable to H where selected gain>=delta H, the same optimization as XV forces
    (1+B U_out/H)(1+B V_d/H) >> u^(7/4)/(M log(2M))
when RHS diverges, uniform for fixed a,epsilon,delta. Still not a macro variation lower bound and not applicable to arbitrary unbounded multipliers.

There is now also a separate UNCAPPED result: on a ray select any actual long cube-certified nonreset population in a dyadic label band [U,2U), with the direct long condition 4w>=g, p>=T_3 (or enlarged XI cube threshold). Zero-close transitions between consecutive selected events have equal adjusted postdeficit and relay E<=B_cut<T_3-1. Direct proves any three-visit chain in this band yields actual twin prime cofactors, each >=T_3, no cap on multipliers. Without that witness, ending gain of zero-close edges Z_band <=(2/3+O(1/U))F_band. Choose disjoint dyadic bands, independently filter the same entire actual eligible block; ending events across bands are disjoint, so sum these bounds with no factor number of bands. Do NOT sum overlapping relay intervals across bands as if disjoint.

New graph application: for every eligible actual tag, choose such a selected population of full events inside its eligible life, independently if desired. Mark the non-zero-close-ending visits (chain starts), total actual selected gain F_all and marked gain J_all. Under finite twins, J_all >=(1/3-o(1)) F_all. For each edge position use a uniform row fraction a_h/n_total of each eligible actual tag (zero when none), so the sum of covered gain weights of any marked tag/event subsets differs from unweighted marked gain by at most Q_h. Therefore covered marked gain >=(1/3-o(1)) F_all-Q_h, and corresponding covered actual wait >=one quarter of that lower bound (all selected visits long). This is a supply restriction on the hard graph when its uncovered gain is small. It does not imply large F_all, nor that marked visits have a large absolute deficit change; they may be first visits, have a long relay, or a nonzero adjusted difference. First visits per dyadic band together cost O(B) gain per tag, hence can be removed o(NT). The remaining marked visits witness either nonzero displacement or large relay, with no bounded multiplier condition. This uses uniform row assignment only for an arithmetic population bound on the relaxed graph, not as the exact original backward kernel. The direct chain theorem applies on full actual selected events; no fabricated continuation.
