## 1. Two fixed color partitions, both uniformly small

Keep XIV original individual eligibility E_i=[M_i^++h,F_i-h) or empty, historical packets and bound P=dmax L_old=o(b0), with L_old the true large threshold of hysteretic-attachment-residence. The earlier first-large key V_i^+ is the actual first true vertex with full original physical population >=L_old, including tick. Any original pair with at least one actual incoming branch >=L_old has distinct first-large keys: a member of that branch was already large strictly before the birth, and two members with the same earlier first-large vertex could not first meet now. For each V all fresh first-large tags come from incoming branches of size <L_old (otherwise predecessor already large). Therefore each first-large class has at most dmax L_old members, even when an older giant cohort is present. Assign singleton colors to tags without such vertex (their E_i is empty). This is a different partition from historical packets; neither refinement relation is assumed. Each original retained backward pair differs in BOTH colors.

For a finite eligible population S of size n define f_c(S)=(n²-sum color_counts²)/(n+R) for each of the two partitions c, R=round sqrt(P b0) with P the common upper bound dmax L_old. Define f(S)=min_c f_c(S). Every f_c is nonnegative, monotone under individual insertion and superadditive over disjoint populations by XIV. The minimum of any finite family of nonnegative superadditive functions is superadditive: min_c sum_j f_c(S_j)>=sum_j min_c f_c(S_j). It is also monotone. For k removed tags choose a minimizing color for the SURVIVING set, so
    f(S)-f(S') <= f_c(S)-f_c(S') <= k+kP/R.
The lower bound zero follows by monotonicity. This proves the same retirement surplus estimate as XIV. It does not assert that the intersection of the two permitted-edge graphs has the same superadditivity (in general it need not). We upper bound its pair count by the minimum of the individual color counts. Any further fixed partition with uniformly o(R) class sizes and differing colors for every retained pair can be included.

## 2. Recover pair ages via a monotone component partition

Use the static true-birth actual-large predicate, original first-birth age and static pairwise rank-age limits (bidirectional-rank-age-survivor-cut), and any other static pair predicate or lower eligibility endpoint whose original clock was already retained. Construct a finite abstract weighted graph on the original root identities: each symmetric unordered pair which passes these STATIC tests and actually meets gets an edge with activation coordinate a_ij equal to its static lower age horizon (max of all retained lower bounds, including actual true first birth). May include individual lower starts in a_ij as well. For an original directed mask take the union with its transpose for an upper bound. Never add an edge for a pair that fails a chosen static test. Do NOT expire these abstract edges at terminal time: their only role is connectivity, not actual residency. A pair that never has eligible overlap can be omitted entirely, an optional static tightening. Denote by P(x) the partition into connected components of edges with a_ij<=x. As x increases partitions only coarsen. Each actual original eligible pair belongs to the same component. We allow transitive connections that were not permitted original edges; this is the exact relaxation. Dynamic slab-specific rank gates and arbitrary noninterval masks are not asserted recovered.

On each actual arrival edge at x, take only the original individually eligible tags, intersect with P(x), and write their nonempty groups S_j(x). Define
    a_age(x)=sum_j f(S_j(x)).
Every retained original ordered pair is within one group and has different colors in both partitions. Let n_j=|S_j|, d0=max(b0,b_exit) original unfrozen denominator, A_old,j retained ordered count. Then A_old,j<=min_c A_c(S_j), and
    A_old,j/d0 <= f(S_j)+(R/b0)n_j.
Proof is XIV (1), group by group; d0>=n_j. Sum n_j<=full actual tag count, so the nonnegative integrated error is o(NT) uniformly. Thus W_B<=V_age+o(NT) with V_age=int a_age omega and U_age=int a_age. At identical individual intervals and R,
    0<=a_age<=f(S_all)<=f_historical(S_all)=a_R.          (1)
The first inequality of upper bounds is superadditivity, not a claim that the true pair count has that property. Consequently V_age<=V_R and U_age<=U_R, a nested upper improvement. It permits keeping all earlier whole-clock routes by minimum, without double-counting credits.

Construct the abstract component partition by sorting finite pair activation edges and running union-find; retain only effective unions, at most N-1, with their activation horizons. A Kruskal reconstruction tree (parent at each effective union, nondecreasing activation coordinate along ancestry) answers component membership at any x by ancestor lookup. All pairwise original ages may vary; no factor number of age thresholds is required in the asymptotic upper error. The pair graph itself can be quadratic to build; no near-linear complexity claim for construction.

## 3. Exact signed graph ledger with nonnegative age credit

At a fixed gain coordinate, process eligible retirements first, then physical completed-state merges using left-limit abstract partition, then coarsen the abstract partition at x, then insert individual starts. Within an actual edge only the retirement/coarsening/insertion operations occur. Physical merge superadditivity holds group by group with the same fixed left partition even if color labels overlap between inputs; at actual poststate the d value is common. At each abstract coarsening, actual eligible groups in any physical state merge only in the denominator, not in the actual trajectory, and superadditivity gives a nonnegative increment. This is a new activation credit, not an added actual coalescence. For interior edge operations use the actual continuous affine d(x). No ghost trajectory, and no sum of d over historical retired members. Count coarsening changes only on actual eligible populations present on that edge/state.

Denote C_age=sum d times these nonnegative abstract-group coarsening increments; C_merge,C_start the analogous physical merge and start credits for this SAME graph. At retirement, apply the Section1 bound to each preexisting group separately; if k retire overall, total excess<=kP/R. Thus S_age<= (P/R) Z_elig=o(NT). Exact edge integration by parts, same endpoint ordering as XIV, yields
    2 V_age=U_age-C_merge-C_start-C_age+Z_elig+S_age.     (2)
All three C terms nonnegative. The Z_elig,Z_not terminal accounting is precisely XIV: Z_elig+Z_not<=Z_all+Nh. Under finite twins the new sufficient criterion is
    liminf [U_age-C_merge-C_start-C_age-Z_not+6(D_l+D_h)]/(NT)<1.  (3)
The exact S_age and terminal shift can also be retained, with the original o(NT) denominator error. Note (1) compares the exact backward envelopes V_age and V_R, NOT each individual credit nor the simplified scalar after discarding signed retirement terms. It is invalid to add old XIV credits to the new ones.

At a dense individual start in its age component S, if n>=ell R before insertion, both color diversity increments >=1-(R/(n+R))²-(2P+1)/(n+R+1)=1-o(1). Since min(f_c+delta_c)-min f_c>=min delta_c, the same lower bound holds for f. Consequently C_start>=(1-o(1)) sum of actual interpolated deficit at these dense starts. Sparse starts can still have large deficit but no comparable immediate debit. For a component coarsening with disjoint groups S_j, define local loss q(S)=|S|-f(S)>=0. Its increment equals sum_j q(S_j)-q(union), a nonnegative quantity; hence C_age pays exactly the gain in coverage multiplied by the deficit at that coordinate. This connects the new missing gain Q_age=L_ind-U_age to the rate of release of its age-group restriction. No fixed positive deficit lower bound at releases or dense starts proved here. In particular if a large low-deficit group already exists, (3) may still be difficult.

## 4. Direct latest double sieve, with scale and multiplier restrictions

Direct c508001 proves for an arbitrary selected nonreset population with polynomial labels p>=X^a,a>1/14, fixed multiplier cap M (adjusted postdeficit=2hp,1<=h<=M), and actual consecutive selected transitions, the close-ending gain bound O_M,a(X(B_cut+1)(A_cut+1)/log² X). Conditions A_cut+5B_cut<=(T_label-1)/2, B_cut<T_label-1 ensure an automatically long successor. No first-long or prime cofactor hypothesis is required. This is a count over the entire O(X) horizon range, not O(local block length). Consequently along ANY individual original eligible ray (length<=H=X/u^.25) the same bound holds, even if the block is shorter. With polylogarithmic cutoffs (B_cut+1)(A_cut+1)=o(u^(7/4)) it is o(H). Summing along all actual tag rays gives o(NT) ending gain and wait (w<=3g); do not sum a separate O(X) error over many short tiles. Graph a_age<=n then also permits this deletion for the corresponding eligible focal clock only if the selected list is chosen on each actual ray, or a common edge selection whose contributing tags execute its actual predecessor inside eligibility.

For any actual eligible contiguous block gain G, selected gain F, outside gain U_out=G-F, variation V_d, and cap B (original max selected prime), direct inequality
    F <= B + O_M,a(X(B_cut+1)(A_cut+1)/u²)
           + B U_out/(B_cut+1)+B V_d/(A_cut+1)
applies. In a block of gain comparable to H with F>=delta H, optimizing cutoffs as in direct (10) now forces
    (1+B U_out/H)(1+B V_d/H) >>_delta,M,a u^(7/4).
Indeed if the product is smaller, choose B_cut,A_cut as ceilings of a large constant times B U_out/H, B V_d/H; both polynomial in u, so automatic-long conditions hold, and two relay terms <=delta H/4, forcing sieve term >=cH. In particular U_out+V_d=Omega(H u^(7/8)/B). This is the correct original-lifetime scale, weaker than the direct macroscopic u² product. It is not a constant fraction of H. Moreover the deep persistent source of VII has deficit >>B, hence a bounded positive multiplier population need not exist there: for high labels <=B, deep postdeficit requires h>>1. We cannot import the fixed-M estimate into that deep sector without a different argument. This is a separate arithmetic supply constraint on eligible low/moderate deficit rays, not a proof that (3) holds.
