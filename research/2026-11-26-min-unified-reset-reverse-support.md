## 1. Exact reset phase and reverse graph

Retain original canonical prime-root tags, initial C0=2M-2,t0=M+2, N~X/log X, G_i<=H, p<=B. An ordinary phase state is (C,t) with C=0 mod4 and d=2t-C in {0,6}; write t=C/2+3I, I in {0,1}. Canonical roots are phase states. Every actual adjusted reset has J=0 mod4 and n=J/2+3I. For any actual complete event arriving at this state with label p, the eligibility congruence gives J+2I=0 mod p, since J=C+p-1. This is true also for p=3; any event arriving at a phase state is an adjusted reset. If both its arrival and departure are phase states, p=1 mod4 by the gained horizon congruence. All these facts concern complete events, not arbitrary waiting ticks.

Fix Y>=7, P<=B. Make the directed graph on phase states with edges the actual complete MIN events between phase states with Y<=p<=P, using the union of original tag paths. Outdegree <=1 by deterministic MIN. All edges increase C. For a target (J,n) of side I, each predecessor label is a divisor p>=Y of J+2I; it fixes C=J-p+1 and leaves only two possible predecessor ticks C/2 or C/2+3. Therefore indegree <=d_Y=max(2,2 floor(log(7X+2)/log Y)). This graph may have fewer edges than the actual true waiting-vertex graph. Do not use its indegree bound for nonreset or waiting-state attachments.

At a canonical prime root (C0,t0), I=1 and C0+2=2M. Since M>B, no actual odd label p<=B can give a complete event arriving there. In particular all canonical roots are leaves of the reversed high reset graph. A root can still join a waiting plateau at that time; the statement does not exclude actual wait-edge coalescence. For a fixed phase target v and all distinct prime roots whose ENTIRE prefix to v consists of these high reset edges (allow length zero), let k_i be the length. The root-to-v paths are distinct leaves of the reversed tree (outdegree<=1 forward, C increases), so
    sum_i d_Y^(-k_i)<=1,   mean_i k_i>=log(n_v)/log d_Y.   (1)
The first bound is the finite tree Kraft inequality; Jensen gives the second. Their average prefix gain is >=(Y-1) log(n_v)/log d_Y. This is not a bound on arbitrary first-large coalescence: most roots may enter via other edges.

General actual suffix seed version: for each tag reaching a phase vertex v, trace its maximal consecutive high reset phase-edge suffix backwards to a seed phase vertex (zero-length allowed). Let b_v be the maximum number of these tags sharing a seed. Determinism gives a unique seed-to-v depth. At most b_v sum_(j=0)^k d_Y^j tags have suffix depth<=k. Thus for n_v>=2 b_v sum_(j=0)^(k-1) d_Y^j at least half of them have traversed >=k high reset edges, actual suffix gain >=k(Y-1). This is a quantitative merge alternative, not assuming a small seed multiplicity. If Y>=X^a fixed, d_Y bounded, many independently entered reset strands require logarithmically many reverse levels unless seed masses large. At the original H scale, even B log N=o(H); this argument alone cannot give a macro missing lower. No independent multiplication of the seed bound over different targets.

## 2. Reset ordered-pair supply with arbitrary actual support

On each original tag choose ANY list of adjusted resets with Y<=p<=P, possibly only selected actual core events. Include the actual gaps from all other events; do not restart the list at core boundaries. Let S_i be its distinct label support, s_i=|S_i|, G_i<=H total actual gained length, F_R its total tagged selected reset gain over tags, R_w=sum r E over consecutive selected edges (ending prime r, E actual intervening gain). The first vertex costs <=P per tag. Fix integer K>=0, K<Y-1. For E<=K, p!=r by exact repeated-label spacing. At fixed ordered p,r, E and sides I,J, first horizon C obeys CRT modulo pr, so the ending gain over the original interval is <=(r-1)(1+G_i/(pr))<=r-1+G_i/p. Each original list has at most one edge starting at that horizon. Four side choices and K+1 relays give
    F_R <= NP + R_w/(K+1)
       +4(K+1) sum_i [(s_i-1) sum_(r in S_i)(r-1)
                        +G_i(s_i-1) sum_(p in S_i)1/p].    (2)
Interpret the bracket as zero for empty list. In particular <=NP+R_w/(K+1)+4(K+1)(P+H/Y) sum_i s_i². Both the physical supports and relay weights refer to the original selected lists, not all possible labels or average core masses. No nonreset divisor-support bound applied at d'=0 or6; such a bound would fail because the adjusted coordinate is zero.

For F_R>=rho NH and R_w<=K0 NH, fixed positive rho,K0, take fixed K large enough that relay tail<=rho NH/4. For any subpopulation of tags with s_i<=c sqrt(H/(P+H/Y)), its total selected reset gain <=NP+rho NH/4+4(K+1)c² NH. Choose c small enough. Then the remaining tags carry >=rho NH/2 for large X, hence at least rho N/2 tags have
    s_i > c sqrt(H/(P+H/Y)).                              (3)
At Y,P comparable sqrt H this forces Omega(H^(1/4)) distinct reset labels per such tag. At Y,P comparable sqrt X the lower bound is Omega(sqrt(H/B))=Omega(X^(1/4)/u^(1/8)). The budget R_w=O(NH) is an additional hypothesis, not a consequence of small unweighted complementary gain. In particular the reset-dominant branch of XXIV is not excluded merely because the ordinary deficit is bounded.

If Y and P have bounded ratio, P²=O(H), and every tag in a subpopulation has s_i<=s0 fixed, one can use K+1=floor(c Y) for sufficiently small fixed c=c(s0,rho,P/Y,H/P²), since P+H/Y=O(H/Y). The close term <=rho NH/4, and tail <=P U_out/(K+1)=O(U_out), with U_out actual complementary gain on those tags. Therefore macro selected reset gain with bounded support on this subpopulation forces macro complementary gain (even without a bounded R_w assumption). This is conditional on the stated support and label scale. For P²≫H use K+1 on scale H/(P+H/Y), retaining the actual factor P/(K+1).

## 3. Rough successor improvement for the smaller scale

For a close reset pair E<=K, its first postdeficit <=6 and intervening ordinary variation upward <=5E, so ending predeficit <=6+5K. Since ending reset has d'>=0, 2w>=g-6-5K. If 6+5K<=(Y-1)/2, the successor is long (4w>=g); both its neighbors have no odd factor f with 9f<Y-1, by the actual MIN competitor clock <=2f. This is valid even when the intermediate events are nonresets. For fixed p,r,E,sides write first horizon C=C_*+pr z; successor cofactor q=(C+p-1+E-e_2)/r=q_*+p z and opposite neighbor r q+2e_2. For odd f<Y their two roots are distinct (slopes nonzero and determinant 2e_2 p), so the earlier dimension-two Selberg upper sieve applies to the CRT parameter interval. Pad its length to L=ceil(H/(pr))+2. Choose sieve cutoff floor(min(L^(1/12), (Y-1)/16)), with bounded cases handled trivially. The CRT interval error <=L^(.5), absorbed in L/log²(2+min(L,Y)). Thus ending gain count <=C(r+H/p)/log²(2+min(Y,H/P²)) for each tuple, with absolute C. No prime cofactor assumption, no independent distribution of phase residues. In (2) the close bracket may therefore be divided by
    Lambda²=log²(2+min(Y,H/P²))
at the cost of an absolute constant. If Y->infinity and P²=o(H), Lambda->infinity. Under the same F_R and bounded R_w hypotheses, fixed K works eventually, and the support lower (3) strengthens to Omega(Lambda sqrt(H/(P+H/Y))) on a positive fraction of original tags. At P² comparable to H the log factor is bounded. In the bounded-ratio lower-scale case and growing Lambda, this is Omega(sqrt(Y) Lambda). No upper on actual support derived; the gain remains possible for large label diversity.

## 4. Prime-root precursor: average the triple singular factor

This is a different use of roughness, directly on the original prime-root ensemble rather than on a single physical ray. Fix delta>0 and consider any actual event with p>=X^delta and 4w>=p-1. Its prehorizon C=C0+a for a nonnegative EVEN integer a<=H, and both C+-1 avoid odd factors f with 9f<p-1. In particular for a fixed a, roots M and their two linear forms
    M, 2M+a-3, 2M+a-1
avoid primes f<=z=X^eta with fixed 0<eta<min(delta,1/12). The three pair determinants are a-3,a-1,4 (up to sign); for even a their product is nonzero. For f>3 all three forbidden residues are distinct except if f divides (a-3)(a-1). Use the fixed-dimensional upper Selberg proof from [9e3203a](https://github.com/tara-sooo/A166944-Lean/blob/64335472d06ac37b03076a7f59c5cb17e854c131/research/2026-11-26-min-direct-repeated-cofactor-cluster-sieve-and-stratum-capacity.md), with dimension3 and its exact singular factor J_3(n)=prod_(f|n,f>3)(1-3/f)^(-1). The proof applies with the smaller cutoff z, yielding
    #roots at shift a <= C_delta X J_3(|a-3|)J_3(|a-1|)/log³ X.
The additive sieve error z^6=o(X^.5 or X^.6) is absorbed; all candidate forms are positive and >z for a>=0 and M>=X. No assertion that the actual event is determined by the sieve.

Average over even 0<=a<=A. The square mean sum_(n<=L) J_3(n)^2=O(L): expand J_3(n)^2=sum_(d|n) g(d) over squarefree d, g(f)=(1-3/f)^(-2)-1=O(1/f), g>=0; sum_d g(d)/d=prod_(f>3)(1+g(f)/f)<infinity. Cauchy on the two shifted factors (abs arguments nonzero, bounded multiplicity) gives sum_a J_3(|a-3|)J_3(|a-1|)=O(A+1). Union bound on roots, therefore
    #prime roots with a high long event at age <=A
         <<_delta (A+1) X/log³ X.                       (4)
This applies even if the preceding prefix contains arbitrary other labels. The averaged singular factor removes the extra loglog losses from a worst-shift bound. Since N~X/log X by the prime number theorem, for A=o(log² X) the fraction tends to zero. For fixed rho>0, if >=rho N tags have a high long event somewhere, choose A=c_(rho,delta) log² X so at least rho N/2 of those tags have first such prehorizon age>A. Their actual prior wait >=(A-6)/2 by canonical deficit nonnegative. In particular any root beginning a high-reset phase-edge path with label>=X^delta is a high-long root for large X, so o(N) tags can have such a pure prefix; their total tagged pure-prefix gain is o(NH). For arbitrary growing Y without polynomial lower bound, pure high-reset root fraction still o(1): take any fixed finite prime cutoff f>=5, use PNT in reduced residue classes mod its fixed product, exclude the two distinct nonzero residues of M for 2M-3,2M-1 (both distinct from 0 for f>=5), then send cutoff to infinity after X. The product of (f-3)/(f-1) tends to zero. No uniform rate for that version.

Connection to XX: if on a fixed fraction of tags the first high-long event prearrival occurs STRICTLY before their first true L-large vertex (or they never reach L), every complete event preceding that prearrival has exit mass<L and contributes >=1-theta of its wait to the strengthened missing measure. Apply (4) on that fraction, yielding missing lower Omega(N log² X). If first-large is at or before prearrival, instead the age may be in the already merged prefix. No subtraction of an O(NB) fringe in this strict case; equality at the large vertex is not included. This bound is still o(NT) in scale, so cannot by itself contradict the finite-twin overlap loss. A single later rough horizon does not control the full intervening age at H scale.

## 5. Direct flat and uncapped transfer

Direct 6433547 fixed ordinary deficit D0>6: eligible high p must divide one of D0/2,(D0-6)/2, side unique for p>=7. For polynomial Y and actual canonical D0=O(H), distinct high support is bounded. Thus actual contiguous flat high-only nonreset run has gain O(P), using its pair theorem. Apply on actual complete core words or original tag events. Unlike resets, this uses positive deficit divisors. For arbitrary nonreset list, direct's cap-free group counting (allow c=0, multiple high divisors) transfers to lifetime H with b=max(1,floor(log(3+5H/2)/log Y)), m=1+floor(log2(P/Y)). Use bins Y L assigned by first horizon and ending band L. Per band O(1+H/(YL)) bins; the ending-state ranges are bounded by selected-post variation, disjoint within same band. Geometric sum L<=2P gives
    F_close << b²(A+1)(K+1) [N(Hm/Y+P)+P V_w/Y].        (5)
Here V_w is XXIV weighted selected-post variation, with all ending labels >=Y. +NP term inside bracket essential when bins exceed H. For medium P,Y comparable sqrt H and b bounded, fixed A,K: if V_w=o(NH), close supply o(NH); to bound total selected gain additionally require R_w=o(NH) or use fixed large K with bounded R_w. This cap-free criterion does not require small multiplier or a shallow initial deficit. For bounded V_w/NH but not vanishing, use XXIV's stronger small quadratic cap theorem; neither proves actual budgets small. The proof in this section uses the direct divisor count, not the new reset support theorem. Do not mix selected lists or add their residuals twice.
