## 1. Exact excursion closure and the last-entry section

For fixed H>h0>3 and gain budget B=4H, use all canonical A in [R,2R], 6|A, h=3 at birth. Stop at first H or first gain>B. State (x,h), signed clock n=h-x/2, one tick either idle (x,h+1) or event p -> (x-p+1,h+1-(p-1)/2). Only idle ticks increase height; at a given physical state and root A, total gain=A-x. The age at H is H-3+(A-x)/2. Spatial range [R-B,2R], even x, h>=0 before stop.

Define f(x) to be smallest allowed A with a first h0 hit at x; infinity if none. Define a(x) instead by minimizing over ALL upward entries into h0 from h0-1 before stopping, including first entries and entries after one or more downward excursions. The same root may have several entries, but a(x) is only a minimum, not a multiplicity. At an entry x, define the deterministic excursion map ignoring the ancestral budget until the path's endpoint or the spatial/height domain boundary:
- follow until first H or until a drop strictly below h0;
- if it drops, continue until its next upward entry into h0, or until exiting the allowed domain;
- if it hits H before dropping, it is a terminal success.
This is finite in the domain: at each event x decreases, at each idle tick h increases, so the state graph is a finite DAG. Every returned entry has x'<x because a drop requires a moving event p>=5. Gain is monotone, so a return or success is budget-admissible from A iff A-x'<=B and the path did not leave the spatial domain. In particular a smaller ancestor is never disadvantaged by this substitution.

Start a with f. Sweep x descending, applying the excursion map to each finite a(x). At a returned entry x', update a(x') by min(a(x'),a(x)), when budget allows; at a success x' at H update the corresponding output minimum. Then:
  (a) the resulting a is EXACTLY the all-upward-entry minimum map;
  (b) the output map is EXACTLY the full canonical first-H minimum map.
Proof: every path decomposes uniquely into its first entry, a finite series of excursions and returns, and its last successful confined part. Replacing a root by the smaller ancestor at a shared state does not increase future gain or change the suffix; it has not already reached H, by definition of entries. Conversely every finite propagated minimum represents an actual canonical witness. All return edges point toward strictly smaller x, so the descending sweep processes every predecessor before the target. This proves both inclusions and equality of minima. Equivalently, inject all entries a(x) at the lower section and follow the deterministic true graph restricted to the closed height strip [h0,H], stopping at H or the first drop below h0. It yields the same exact minimum output map. Indeed every successful canonical root has a last upward entry, after which its path never drops below h0. This formulation does not require the post-entry height to be monotone, and it does not assert that first entries alone suffice for confined transport. This is a last-entry refinement of the earlier exact first-hit min-plus composition in 0c4cd9e.

## 2. An arithmetic defect bound that is uniform over ANY occupied cohort

Let W=H-h0, h0 comparable to H, H of fixed positive polynomial order at most O(sqrt R). In the closed strip [h0,H] with the above spatial domain, define a trial graph that ignores eligible prime labels p>Z, otherwise selecting the exact least eligible label, and terminates at H or the first drop below h0. Choose a fixed polynomial threshold Z>=R^alpha for some fixed alpha>0; Z<=2H+3 if a nontrivial truncation is desired. If Z>2W+1, every successful confined trial path necessarily has moving labels <=2W+1: preheight<=H-1 and landing>=h0 imply p<=2W+1. Labels in (2W+1,Z] are still tested and may cause a down-exit; they are not silently removed. The ignored larger labels can only cause a true down-exit if they fire inside this band.

A changed outgoing transition has true winner p>Z. At preheight h in [h0,H-1], the exact eligibility pins imply
    p | 2h+3 (plus) or 2h-3 (minus),
    x=-s mod p.
For h comparable to H the two height integers are positive O(H); each has at most log(O(H))/log Z=O_alpha(1) prime divisors above Z. For each candidate p, the spatial slab contains O(R/p+1)=O(R/Z) positions. Thus the total number of CHANGED PHYSICAL STATES in the strip (not root incidences) is
    E_strip <= C R W/Z * log(O(H))/log Z = O_alpha(R W/Z).    (1)
This requires no statistical assumption, no fixed residues for the actual cohort, no slow wait, and no small primorial. It also holds for the trial restricted at the strip boundaries (a true down-exit versus a trial idle is a changed transition). 

Take any set of actual reachable entries at h0, with one genuine ancestor A per entry, not necessarily all entries or the first entries. Run the trial with the SAME total budget B, stopping upon down-exit or H. Let N_trial be its distinct successful sinks. Select one genuine starting witness per distinct trial sink. Two successful trial paths with distinct sinks cannot share a physical vertex, because the trial is deterministic and stops on first H; the root-specific budget does not affect the actual edges of successful paths. If such a path contains no changed physical state then its entire suffix is true, yielding a real first-H witness with the same budget, assuming the original entry prefix did not already hit H. Therefore
    N_true >= N_trial - #changed states >= N_trial - E_strip. (2)
In fact the common-path count is a stronger certificate when available. There is no compounding error per tick and no dependence on how concentrated the occupied entries may be. This is an integer distinct-sink form of the earlier residual method with an explicit arithmetic upper. It differs from 07503a49, whose longer relative-defect estimate required a special p,v source or averaging over both coordinates of a local lattice. Here the upper is uniform for arbitrary actual entries even at a SINGLE fixed height. The gain budget is not reset at the lower section.

Concrete H=R^.4, W=floor(R^.2), Z=floor(R^.3): E_strip=O(R^.9)=o(R/L²). Another choice W=floor(H/L^4), Z=floor(H/L): E_strip=O(R/L³)=o(R/L²). These give a comparison over a polynomial width instead of the earlier logarithmic transfer, but the cutoff is polynomial too; this does not reduce the successful trial lower to the earlier small-primorial model. In either case a lower N_trial>>R/L² from actual entries would prove the target. No such trial lower has been shown.

There is also a global hybrid version: alter the deterministic graph only inside a finite collection of height strips, ignoring primes above their respective cutoffs Z_j, and keep the true transition elsewhere, including below each strip. From actual canonical births, compare distinct successful trial first-H paths to true paths as in (2). A path may cross each strip many times, but distinct successful sinks have vertex-disjoint paths. The total loss is at most the number of changed vertices in the UNION, bounded by O(R sum_j W_j/Z_j) for fixed polynomial cutoffs uniformly bounded below. Thus if sum W_j/Z_j=o(L^-2), modification of these sparse bands is negligible relative to the target. This is valid without all-entry maps as input and permits actual excursions outside the modified strips. Covering the entire polynomial height range with such changes at nontrivial cutoffs does not satisfy the small sum condition; the statement is not a global approximation theorem. The exact excursion closure above suggests a numerical and analytic route where true dynamics outside the selected bands supply the entries and the uniform strip bound isolates the remaining uncertainty.

Optional average improvement: for target heights H' in [X,2X] with fixed polynomial X comparable to H, a fixed width W=o(X) and Z polynomial <=O(X), sum (1)'s actual candidate count over all such H'. A preheight h is included in at most W strips. For p>Z its height pin occurs O(X/p+1) times in the union; spatial count O(R/p). Divide by #heights ~X. Average defect
    << R W [1/(Z log Z) + (1/X) sum_{Z<p<=4X+3}1/p].
Use dyadic Chebyshev for the reciprocal-square sum. This is an averaged bound, not a stronger pointwise assertion at a fixed H. For example Z=X/L and W=Z/L^2 it is O(R/L³+R log L/L^4) uniformly on average, and thus small at a positive fraction of heights by Markov. For an actual trial lower at a higher section H'>=H using the SAME budget 4H, distinct successful higher sinks imply at least as many distinct first-H sinks by determinism and monotone gain. This explains how averaging could help select a height without changing the fixed target. No lower over those averaged heights has been derived.

## 3. Terminal scale gap at intermediate polynomial labels

Use Q=2 product_{3<=r<=z prime}r<=L^.25 from the previous small wall argument (z=c log L). Fix 0<alpha<theta=.4, H=floor(R^theta), and consider any canonical first-H witness with gain<=4H, any event anchor y,n,p,s, postheight h_a<H, and subsequent gain d=y-x<=Q to its terminal x. No restriction on the intervening labels. Assume p>=R^alpha. Let q=qmin(x). We prove that outside a set of o(R/L²) distinct terminal sites (uniform over ALL such witnesses), every such p satisfies
    q > p exp(sqrt L).                                  (3)
This is a necessary property of the terminal witness, not a claim that q itself is polynomially close to H or that these witnesses exist in density.

Split into q <= p exp(-sqrt L) and p exp(-sqrt L)<q<=p exp(sqrt L).
For the first range use dyadic p bands [P,2P], P>=R^alpha/2. Complete-event wait inequality W_complete<=17 d/8+395/12 from c0e45b0, and final idle<2q, imply
    H-h_a <=13Q/8+395/12+2q
            <=13Q/8+395/12+4P exp(-sqrt L).
For each eligible h_a in this narrow interval, h_a-b_s is positive O(H), hence O_alpha(1) prime divisors p>=P by the height pin. Each label fixes y=c_s mod p in O(R/P) positions and clock is determined. Each key leads to at most one first-H sink, irrespective of ancestor multiplicity. Therefore the number of distinct sinks in this band is O(R (Q+1)/P+R exp(-sqrt L)); sum O(L) bands, giving o(R/L^C) for every fixed C.

In the comparable (subexponential ratio) range, q>=R^(alpha/2) for large R; p<=2H+3, q<= (2H+3) exp(sqrt L), so pq<=R^(.8+o(1)), with polynomial CRT room. Since q divides x+t for t in {+1,-1}, write x=q v-t. The anchor pin y=x+d=c_s mod p, c_s=0 or2. If p=q, this would give d=c_s+t mod p, an odd residue in {-1,1,3}, impossible for even 0<=d<=Q<<p. Thus p,q distinct. The pin prescribes one residue of v modulo p. Both forms v and q v-2t are R^(alpha/2)-rough because x±1 have minimum factor q. In a parameter interval of length O(R/(pq)) polynomially large uniformly, the standard elementary two-form Selberg upper from earlier checkpoints yields O(R/(pq L²)). Good-prime determinant 2pq and the omission of primes p,q cost a bounded factor; if a form is forced divisible at an omitted prime it cannot enlarge the upper. Count possible x only, not clocks. For fixed p the sum of reciprocals of q in the comparable band is O(L^(-1/2)), by dyadic Chebyshev; the reciprocal p sum over [R^alpha,2H+3] is O_alpha(1). Sum signs and O(Q+1) even offsets to get
    N_comparable << R (Q+1)/L^(5/2)=O(R/L^(9/4)).       (4)
Together these prove (3), with total exception O(R/L^(9/4)). This extends previous terminal exclusion from near-top labels to EVERY label of any fixed polynomial order, using both terminal alignment when q is much smaller and the extra factor pin at the terminal site when q is comparable. In this version theta=.4 ensures pq has polynomial room; do not automatically claim the comparable estimate at theta=.5. More generally it holds for every fixed theta<.5.

In particular, if a density-scale set of intrinsically active first-H sinks has qmin(x)<H/16, then for any fixed alpha>0, outside o(R/L²) exceptions, every terminal polynomial anchor within displacement Q must have p<qmin(x) exp(-sqrt L). The last nonsmall label (if any) is such an anchor whenever polynomial, since small-only suffix gain<Q. This gives a new restriction on the intermediate-terminal gateways of 7499425: they must exhibit scale separation between the final roughness and the incoming label, or have subpolynomial incoming labels. It does NOT exclude the latter cases, furnish their canonical ancestry, or imply the full density lower. It indicates that the next lower-bound effort should include repeated small/medium entries into higher roughness sites, rather than focus on comparable prime pairs.
