# Integration XXIII: all-scale deficit-shell sieve on the original lifetime

2026-11-26 JST. Parent f1f6e1cc8a57adfc3252c4e5ba13654e4a3bf73f. Direct preflight [bc3b10b](https://github.com/tara-sooo/A166944-Lean/blob/bc3b10b88fe25e845935164e571bed5f650ace87/research/2026-11-26-min-direct-low-scale-localized-deficit-sieve.md). The direct low-scale theorem needs a selected single dyadic label band, a cap x<=K T^beta and local range/variation budgets. New here: an independent two-prime-line count in DYADIC DEFICIT shells, with a growing logarithmic multiplier cap, sums all label scales at once and retains the short canonical horizon CRT factor. No rough-horizon sieve or polynomial lower bound on the labels. It applies even to noncomparable labels in the same close transition, and to an arbitrary union of exact common-core events when counted once along each full original tag. It gives an upper supply bound for close shallow transitions and a complementary quantitative weighted-relay/variation/deep/upward alternative. This does not force any of the residual supplies to be small.

## 1. Direct local-bin import on a core

Use fixed notation s for the direct label threshold T (not our lifetime). On any actual contiguous original interval of gain G, selected nonresets s<=p<2s, x=(d'-6I)/2=hp>0 with cap x<=K s^beta (fixed K, 1<=beta<2), direct bc3b10b proves close ending gain in one horizon bin of length s²:
    F_close,b << s W_b (A+1)(B_cut+1)/log^nu s,
where W_b=max(s,local x-range+1), nu=2 if beta<3/2, nu=1 if beta<2. Same-label close returns excluded for B_cut<s-1, and |c|<=floor(A/2)+3<=s/2. Bin count now O(1+G/s²), not O(X/s²). Actual disjoint post-to-post variation intervals across bins give sum W_b=O(s+G/s+V_d). Therefore
    F <= O(s+G/s)
       + O((G+s²+s V_d)(A+1)(B_cut+1)/log^nu s)
       +2s U_out/(B_cut+1)+2s V_d/(A+1).            (1)
The first term counts bin-first selected events, U_out is all complementary actual gain, V_d the full ordinary variation. Uniform for s->infty, fixed cap constants. For exact XXI cores G~D, s²<=D, the per-block bound uses D rather than X; sum with b_Q and exact actual weighted relay/variation. One can also apply once per whole original tag, G<=H. This does not itself sum arbitrary bands: complements of different band lists overlap, and no one band with macro gain is forced. The theorem below takes a different route.

## 2. All-scale close transitions under a relative logarithmic cap

On any one actual original tag or actual contiguous complete-event block let the prehorizon range have length <=G, and take an arbitrary selected list of positive nonresets with labels Y<=p<=P<=B, where Y=Y(X)->infty (as slowly as desired), and
    1<=h=x/p<=sqrt(log p).                             (2)
Here log is natural. Consider consecutive selected events (p,h,I,C,x), (r,k,J,C2,x2), relay E=C2-C-(p-1), postdeficit difference v=d2'-d1', c=x2-x=v/2-3(J-I). Close means E<=B_cut<Y-1 and |v|<=A with Q=floor(A/2)+3<=Y/2. Both cutoffs nonnegative integers. Same-label return requires E>=p-1 (direct spacing lemma), hence p!=r. Also c!=0: if x=x2 positive then pr divides x, hence h>=r and k>=p. If p>=r, k<=sqrt(log r)<r<=p, contradiction; if r>=p use h. This does not require sqrt(log P)<Y, and in particular no global unique-factor cap in x is needed. No long condition needed.

Partition FIRST x into dyadic shells L<=x<2L with L=Y*2^j, j>=0 (can pad last shell). x2 in [L/2,3L] as |c|<=Y/2. Since p<=x,r<=x2, both h,k<=M=ceil(sqrt(log(3L))) and p,r>=L/(2M). For each fixed nonzero signed c,h,k, put g0=gcd(h,k), a=h/g0,b=k/g0. Unless g0|c there are no solutions. Otherwise the necessary residue x=x0+(hk/g0)z produces integral prime forms
    p=x0/h+b z, r=(x0+c)/k+a z,
of nonzero determinant |c|/g0. Reuse the earlier direct translated dimension-two Selberg prime-line bound with J(n)=product_(odd f|n) f/(f-2). The parameter interval can be padded to ceil(Lg0/(hk))+1. Uniformly for all permitted h,k the length is >=L/M², logarithm comparable to log L, and cutoff (parameter length)^(1/12) below both prime labels as L grows. Thus number of possible x at fixed h,k,c is
    << Lg0/(hk log² L) J(a)J(b)J(|c|/g0).             (3)
No bounded-ratio assumption on the two labels or the multipliers. This uses the analytic sieve already proved in direct, not a fresh Selberg proof.

For each such x and fixed sides I,J and relay E, necessary horizon residues C=1-2I mod p and C+p-1+E=1-2J mod r specify one CRT progression modulo pr. In an interval of length G, at most 1+G/(pr) candidate horizons, each at most one actual starting event in our monotone list. Charge ENDING gain r-1 (not maximum P). This gives weighted capacity
    (r-1)(1+G/(pr)) <= G/p+r
                       <= G h/L+3L/k.                (4)
The CRT count is local and uses no equidistribution/rough-horizon hypothesis. Multiplying (3),(4) bounds the shell for fixed h,k,c,sides,E by
    << [G/b + 3 L²/(g0² a b²)] J(a)J(b)J(|c|/g0)/log² L.
Here cancellation of the ending label weight is essential. Drop coprimality in summing positive upper estimates. From prior mean sum_(n<=z) J(n)<<z, partial summation gives sum J(n)/n<<log(2z), sum J(n)/n²<<1. The first coefficient summed over a,b<=M/g0 is O(G (M/g0) log(2M)); the second O(L² log(2M)/g0²). Sum all 0<|c|<=Q via c=g0 c0 and the bounded mean J, giving O(Q) times each corresponding convergent sum g0^-2 or g0^-3. Four side pairs, B_cut+1 possible relays. Consequently one deficit shell contributes close ending gain
    << (A+1)(B_cut+1) [G M log(2M)+L² log(2M)]/log² L. (5)

Sum shells. Since M=O(sqrt(log L)), first coefficient series is summable:
    sum_(j>=0) M log(2M)/log²(Y 2^j)
        << log log(3Y)/sqrt(log Y).
For the second term use L<=P sqrt(log P); dyadic geometric summation with the slowly varying denominator gives
    sum_L L² log(2M)/log² L
        << P² log log(3P)/log P.
For instance split at square root of the largest L; the smaller shells have exponentially smaller squared-length sum, and larger shells comparable logarithms. Uniform for sufficiently large Y<=P. We obtain
    F_close << (A+1)(B_cut+1) [
         G log log(3Y)/sqrt(log Y)
         + P² log log(3P)/log P].                   (6)
The cap (2) is a choice, not a property forced by MIN. More generally h<= (log p)^gamma for fixed 0<=gamma<1 gives first term G (log Y)^(gamma-1) log(2+log log(3Y)) or the simpler G (log Y)^(gamma-1) log log(3Y), and second term P² (log P)^(2gamma-2) log log(3P) by the same summation. For gamma=0 the redundant loglog factor can be removed (M bounded). We use gamma=1/2 only. For a single D-scale core with P²<=D, (6) is o(D) for fixed cutoffs; for arbitrary P<=B this is not true on every D-scale core. Use full lifetimes below. Unlike earlier c4ef87a, no p>=X^a requirement or horizon sieve cutoff; unlike bc3b10b, no single-band hypothesis or V_d in the close-pair count. This is not an upper on total selected gain without further control of the nonclose transitions.

## 3. Weighted tails and transfer to ALL actual core tags

For each original tag select any subset of exact core events satisfying (2) (e.g. long high events in XXII, or actual low cut crossers above S). Use ONE list over its original entire lifetime, even across gaps between cores. Can instead select events outside cores; no change to theorem. For successive selected events use weighted resources
    Rw=sum r E, Vw=sum r |v|,
where r is actual ENDING prime. These sums are over all chosen consecutive edges, and then over original tags. Distinct physical relay intervals per tag are disjoint; their unweighted sum <=total complementary gain. Post-to-post variation intervals similarly disjoint, sum |v|<=total physical variation. The weights are retained instead of replacing them by B. Therefore after paying at most NP for first chosen event of each tag,
    F <= NP + F_close,all + Rw/(B_cut+1)+Vw/(A+1).    (7)
The first and close and tails can be taken disjoint (relay priority); using both full weighted budgets is an upper, not a disjoint equality of their resources.

With G<=H and P<=B use (6) once per tag. Since P² loglog(3P)/log P is eventually increasing, bound it at B. Let
    eps_X= log log(3Y)/sqrt(log Y)
           + (B²/H) log log(3B)/log B.
Here B²/H=O(u^.25), so eps_X->0 even with slowly growing Y, and the second term O(u^(-3/4) log u). Then for arbitrary original selected core subsets,
    F_close,all << NH eps_X (A+1)(B_cut+1).           (8)
No factor number of common blocks, and original tag multiplicities are exact. This upper pays close shallow transitions o(NT) for fixed cutoffs, even across mixed-scale lists. The original H=X/u^.25 is essential for the short-lifetime estimate; no independent multiplication by a full-X error per block.

If F>=rho NT (rho fixed>0), set z=Rw/(NH), y=Vw/(NH). Then
    (1+z)(1+y) >>_rho 1/eps_X.                       (9)
Indeed if product already >=1/eps_X nothing to prove. Else choose B_cut=ceil(K0 z), A=ceil(K0 y) for a fixed sufficiently large K0 depending on rho. These are O_rho(1/eps_X)=O_rho(sqrt(log Y)), within close assumptions for Y->infty. The weighted tails in (7) <=2NH/K0, first term o(NT), and (8) gives (9). In particular Rw+Vw >> NH/sqrt(eps_X) along this branch. For a selected population with bounded Rw/(NH), Vw/(NH), the total selected gain is o(NT) by taking arbitrarily large fixed cutoffs in (7), then X->infty. These are label-weighted relay/variation budgets, not macroscopic lower bounds for unweighted variation. For fixed theta and fixed pin scale S, the required Y->infty is NOT automatic; use the growing pin-only S(X) of XXII for asymptotics. The low crossing mass lower does not imply macro selected GAIN of nonreset shallow crossers, nor does the high-long branch imply (2).

## 4. Uncapped selection: retain deep and upward resources explicitly

For any selected positive-nonreset list Y<=p<=P (no multiplier cap), define deep vertices by h>sqrt(log p), total tagged deep gain F_deep. Let F_up(Lratio) be ending gain of successive selected transitions with r>Lratio p, for any FIXED Lratio>=1. Keep the full-list Rw,Vw, no recomputation after deleting deep vertices. Count only close edges with BOTH shallow endpoints using (8); those edges are also consecutive in the shallow sublist, so valid. All other close endings either are deep (total <=F_deep) or have deep predecessor. If the latter is not a large upward edge then r-1<=2 Lratio(p-1) (p>=3), and each predecessor is charged at most once. Upward edges charged at most F_up. Hence
    F <= NP + O(NH eps_X (A+1)(B_cut+1))
          + Rw/(B_cut+1)+Vw/(A+1)
          + (1+2 Lratio) F_deep+F_up(Lratio).         (10)
One must retain the upward term: a small-gain deep predecessor may feed a very large shallow successor, and a cutoff depending on each p does not make the end necessarily deep. For bounded normalized weighted budgets and macro nonreset F, (10) forces a positive fraction of tagged gain in deep vertices OR upward transitions (for each fixed Lratio). Conversely if both are o(NT) with fixed Lratio, the product restriction (9) still holds for macro F. No assertion of an upper supply on either. For all actual high-long core events (XXII), separate adjusted reset gain F_reset (x=0), use F=F_H-F_reset. Thus the old high-long macro branch cannot be sustained by shallow nonresets with bounded weighted tails; the remaining possibilities are resets, deep multipliers, large upward label transitions, or unbounded weighted tail resource. This is a quantitative restriction on the actual population, not another assertion that a particular single band must dominate. Low crossing supply can use the same theorem if macro selected gain is established, but M_low counts normalized cut mass and may amplify small physical gain. Do not infer that missing hypothesis. The core clock inequality of XXII remains the outer condition.
