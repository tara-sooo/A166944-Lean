## 1. Retain the row denominator without breaking word weighting

Use original actual endpoint transfer, unfreezing and all o(NT) errors of XVII. At actual interpolation x on arrival edge of tag i, b_exit is the original physical exit population, d0=max(b0,b_exit), with b0 the old backward source cutoff. Let S be its individually eligible XVI age group, n=|S|. Let d_i(x) in THIS SECTION denote number of permitted partners in the static relaxation after unfreezing, including true-birth predicate and static lower endpoints, both individual eligibility tests; may drop dynamic slab rank gates as before. To avoid confusion call it deg_i. It is zero for ineligible i, <=n and <=b_exit. This uses only static tests from the same retained original envelope, not a new arbitrary deletion. The exact static row upper after unfreezing is alpha_i deg_i/d0. The XVII hard reserve row upper is alpha_i(chi_i+K/b0), K=R+P_packet=o(b0). Define
    chi_hat_i = min(chi_i, deg_i/d0) in [0,1],
    dmu_hat=(1-chi_hat)dW, A_hat=int alpha dmu_hat,
    M_hat_full=int dmu_hat.
The min row bound follows from min(a+err,b)<=min(a,b)+err; integrate the SAME row inequality, same o(NT) error. If counting deg_i too costly, substitute n/d0, or even min(1,b_exit/b0) as second upper; all statements below use only chi_hat<=min(1,b_exit/b0). Ineligible chi_hat=0. This is a nested row improvement over XVII, not a new graph Stieltjes identity: do NOT apply XVI integer flow identity to chi_hat. Under finite twins, unchanged source partition yields
    int (1-alpha-phi)dW + A_hat=o(NT),
    int(1-phi)dmu_hat=o(NT).
All XVIII-XIX collision/sampling estimates carry over verbatim, since missing fractions of actual wait remain <=actual wait, redistribute over original atoms with same proportions. Assigned missing M_hat=M_hat_full+o(NT) under finite twins. It is possible old missing mass is small while this stronger mass is large. No equality between them assumed.

## 2. Quantitative early actual population threshold

Fix theta in (0,1), integer L=floor(theta b0), eventually L>=2. For each original tag let V_i be first actual true vertex with population >=L, if any, including wait vertices and terminal snapshot. Let tau_i its projected horizon and d_i its ordinary deficit there. If none, use actual terminal (but do not call it large). Define age A_i=tau_i-C0_i and actual prefix ticks W_i^pre=t(V_i)-t0_i, with terminal substitute if none. Exact canonical identity
    A_i+d_i=6+2 W_i^pre.
Every completed event entirely before that first vertex has physical exit population <L, because its pre-jump true vertex (or completed exit) lies before V_i; use the old slot definition, including all actual visitors, or allow a one-event fringe. Hence chi_hat<=theta on each such event's entire interpolation. At most one event straddles V_i, whose wait<=2B. With mu_hat_i total missing clock on this tag (averaged grids, chi_hat independent of grid if same static relaxation), we obtain
    (1-theta)(W_i^pre-2B)_+ <= mu_hat_i,
    sum_i(A_i+d_i) <= 2 M_hat_full/(1-theta)+O(NB).    (1)
For tags without first large, all completed waits are in prefix and no fringe needed. Under finite twins G_i>=T, so #never_large <=2 M_hat_full/[(1-theta)(T-6)] (if use exact exit convention), or add O(NB) in numerator with fringe. For fixed epsilon>0, #tags with prefix age or deficit >=epsilon H <=[2 M_hat_full/(1-theta)+O(NB)]/(epsilon H). This proves for small M_hat=o(NT), almost every root reaches actual b>=theta b0 at age AND ordinary deficit o(H), in the usual convergence-in-density sense. This is much stronger threshold than XVI reserve R=o(b0); it is not a constant prefix-age lower from root spacing. No guarantee all early entrants join same cohort. The inequality itself is unconditional with actual stopped paths, even if finite twins are false.

## 3. A hysteretic physical skeleton with few paths

Use full finite original true graph, deterministic forward successor, no actual splitting; edges are actual wait ticks or completed jump ticks. Compressed waits are allowed only at constant membership, with arrival/terminal/departure vertices retained. Vertex population includes retiring visitors; edge flow counts only actual traversing tags. Let 1<=m<L. In increasing true tick order mark the outgoing edge if (i) there is an incoming marked edge OR the vertex population >=L, and (ii) the outgoing flow >=m. A START is a vertex with population>=L and no marked incoming. A STOP is a vertex with an incoming marked edge or a start but no marked outgoing; it has <m continuing tags (including zero). At a stop choose a witnessed upstream large vertex on a marked continuation into it, e.g. trace one incoming path backward to its last large vertex; at a start-stop choose itself. Every tag at that anchor either retires before continuing past stop or traverses the stop outgoing edge. Thus >=L-m+1 actual anchor tags retire on that continuation, possibly at anchor/stop. They are distinct across different stops: if a tag is a retiring witness at two stops, its actual path contains both anchor vertices. The later anchor cannot be beyond the first stop's outgoing edge, because the tag retires before that edge. If the later anchor is before/at that stop, its marked continuation reaches that stop before any subsequent edge and cannot cross it. The first stop reached from the later anchor is therefore the same stop (including start-stop), contradiction. This is the original retirement witness logic, applied to all hysteretic stop episodes, not only a tag's first return. Thus
    #stops <= N/(L-m+1), total continuing stop incidences <= (m-1)N/(L-m+1).
At a start count all actual visitor tags. A tag's first start membership counts at most once globally. Any repeated start membership requires that tag to cross a previous stop's unmarked outgoing edge since its preceding start: otherwise marked continuation would still enter this vertex (or tag retired). Charge to its last such stop crossing, injectively over repeated start memberships for that tag. Hence
    L #starts <= N+(m-1)#stops,
    #starts <= N/(L-m+1).                              (2)
This includes start-stops and possible historical mergers with retired roots; no historical count is used as a physical flow. A single large threshold crossed many times by retirements cannot generate arbitrary extra chains.

Partition marked edges into actual directed chains: at each marked merge continue the path on the incoming marked branch with largest historical component mass (tie fixed), terminate all other marked chains; at a start with outgoing marked, start a chain. No split at a small attachment to a marked incoming branch. At most #starts chains, mutually edge-disjoint, with
    sum_chain projected gain <= G_all/m <= NH/m.         (3)
Every original tag whose actual first large vertex exists and which never later crosses an edge of flow <m traverses only marked edges after that first large vertex. Every time its chain index changes, its historical mass at least doubles: its marked incoming branch lost to another marked branch of at least the same historical mass, disjoint histories. Hence each such actual suffix uses <=1+floor(log_2 N) chains. At most (m-1)#stops tags ever cross a small edge after first large, by assigning first such crossing to its marked stop. This proof counts ALL later small returns, not just first, for (2); for the tag exception use first only. A complete event cut by a chain switch or endpoint costs <=B in gain, so if desired discard O(NB log N)=o(NT) tagged gain to use only complete events wholly in the chosen chains. A tag may join a continuing marked chain during its wait; start/end fringes also O(B) per tag. No ghost extension; chain may concatenate actual edges supported by different original tags, but is a true MIN continuation at a shared state. Cannot extrapolate the chain past its last actual edge.

Let G_out be original tagged gained length not on marked edges, counting each tag once per traversed gain. By (1), first-large prefixes (or whole never-large tags) contribute <=2 M_hat_full/(1-theta)+O(NB); after first large only exceptional return tags can be outside, each total gain<=H. Thus
    G_out <= 2 M_hat_full/(1-theta)+O(NB)+NH (m-1)/(L-m+1). (4)
Take theta=1/2, m=floor(L/ell) (eventually >=1). Under finite twins G_all>=NT, if M_hat=o(NT), the marked skeleton contains (1-o(1))NT of actual TAGGED GAIN. It consists of O(N/b0) actual edge-disjoint chains with total unweighted gain O(NH ell/b0), and each nonexceptional tag has early, shallow entry by (1) and logarithmically many switches. This covers gain as well as wait: no assumption of lower local clock density, because missing prefix is controlled by canonical deficit and later return by retirement. If G_out has fixed positive normalized lower instead, (4) gives macro M_hat and XVIII-XIX apply to that strengthened measure. This is a genuine alternative to trying to prove macro missing unconditionally. It does not establish that a high-flow skeleton is arithmetically impossible. Neither chain count nor unweighted total length alone bounds tagged gain, since physical masses may be large.

## 4. Direct thickened cut recovery on actual post-large suffixes

Import direct 3e19d7e: odd primorial P_S, K_cut=2P_S>2V with V<=S²; strict pinned cut crossing H_pre<J<H_post with p<=V, or small positive overshoot <=V/2 after any strict crossing. Start a forward corridor with that crossing (respectively after crossing) up to first plateau >=J+V, retain complete events. Every prehorizon inside has 0<|C-J|<=V. If S is beyond all twin lower members under finite twins, neighboring offsets cannot give twin prime witness; least eligible prime <=S, so all waits<=2S. Cutoff L_cut>4S, a=1-4S/L_cut>0. For each completed strict moderate corridor, gain>=V, net ordinary drop >=a V-(a+5)G_low with low labels p<=L_cut. Disjoint corridors per tag, at most one pending, and for small positive overshoot variant gain>=V/2; treat these variants separately unless chosen cuts/corridors are disjoint. All statements apply to complete events in each actual post-large suffix, not to arbitrary clipped gain edges or a fictitious representative path with different terminal. For each good tag in section3 (first large, no later <m), start suffix at first completed-event arrival at/after V_i, dropping at most one event, with initial ordinary d_i^start<=d_i+O(B). Sum over good tags, initial deficit sum <=2 M_hat_full/(1-theta)+O(NB), by (1). Let C_mod count completed designated moderate corridors over these actual tag suffixes, Q their union per tag, L_gain total actual p<=L_cut gain inside Q, P_out total positive variation outside each tag's Q but in same suffix. Telescoping direct net drop yields
    a V C_mod <= (a+5)L_gain + P_out + 2 M_hat_full/(1-theta)+O(NB). (5)
For small-overshoot variant use a V/2. Therefore excess localized demand over actual low gain and outside positive variation lower-bounds M_hat_full up to O(NB); no inherited deficit can be assumed for free at early large entry. In small missing regime, (5) requires demand be supplied by actual localized low gain or outside positive variation unless missing scale itself pays it. This is a weighted per-original-tag budget, no factor number of chains and no assumption of constant physical mass; on skeleton can aggregate with actual counts of tags executing full corridor. If want a per-chain direct sieve, handle changing multiplicity separately (e.g. use actual tag restriction); cannot multiply unweighted count by arbitrary mean cohort. For direct hybrid S=floor(R/loglog R), V=S², L_cut=R, a=1-o(1), surviving moderate strict cuts are included. Resource V C_mod may be submacroscopic even for many cut crossers; o(NT) missing not automatically o(V C_mod). No dominance of moderate cuts assumed. This identifies another explicit supply test, not final contradiction.
