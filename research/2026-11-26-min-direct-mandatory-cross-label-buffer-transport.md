# Mandatory cross-label buffer transport and reduction of the same-label branch

Continuation of [d422023](https://github.com/tara-sooo/A166944-Lean/blob/d422023036a9cb61ebe6e87890fa28dcecf21ae9/research/2026-11-26-min-direct-causal-recycling-scale-and-stratum-transport.md). The previous causal height matching left a same-label one-stratum-loss branch alongside cross-label transport. Here show that every source participating in that branch must FIRST pay a full intervening buffer of width p-3 through distinct-label downward events. This reduces the two transport alternatives to one macroscopic cross-label population (allowing an expanded guard and a larger downward-label range). The result does not rule out one-stratum returns or cross-label transport themselves. It is conditional on the preceding fast-gain/narrow-local-guard/low-label-scarcity regime when used macroscopically.

## 1. Exact forbidden downward band

Use actual adaptive MIN coordinates H,p,g=p-1,w,I,e=1-2I,d,d'=d+2w-g. For p>=5, d'=2ph+6I with nonnegative integer h. Ordinary downward events have drop at most p-3. Fix any p>=11 and integer h>=1. Define the open deficit band
    B(p,h)=(2ph-p+3,2ph).
Its length is p-3. NO actual downward event of label p can traverse a positive length of B(p,h), irrespective of its own multiplier, clock, horizon, or how it was reached. Indeed if its ending multiplier k>=h then its ending deficit is >=2ph. If k<=h-1 then its starting deficit is at most
    2p(h-1)+6+(p-3)=2ph-p+3.
The open endpoints avoid ambiguity; changing them on a measure-zero set has no effect. This is the fixed-label deficit barrier in interval form, aligned to a particular source multiplier. We use all its levels simultaneously rather than just a single cut.

Consider an upward source s of label p, ending at a=2ph+6I, and a later downward target t of the same label with ending multiplier h-1, so b=2p(h-1)+6J. Suppose they have positive causal matched height weight in the sense of d422023. In particular their upward and downward segments overlap in positive length. The target pre-deficit is <=2ph-p+3. Positive overlap forces the source pre-deficit strictly below that bound. Its post-deficit is >=2ph. Consequently the source upward segment covers the ENTIRE band B(p,h), and by the time of the target pre-state, the deficit is below or at the lower edge.

For almost every level u in B(p,h), after the source, the FIRST downward crossing of u is therefore strictly before the target (the target itself has no positive overlap with the band). By the forbidden-band property this downward event has label different from p. Since it is the first downward crossing following this source, the causal matching pairs it to this source at that level; there has been no intervening downward crossing to consume that unit. Thus the same source provides exactly p-3 units of matched height weight through different-label downward events in the band. There can be arbitrarily many intermediate ups and downs, but the first downward crossing at each level is unique. This is an actual MIN trajectory assertion; no bounds on the relay or multiplier are imposed.

For a fixed source, all its one-stratum same-label targets end in one of the two positions 2p(h-1) or 2p(h-1)+6. Their actual downward segments lie in [2p(h-1),2p(h-1)+p+3], of length p+3. Because the causal matching never uses a source-level unit twice, the total one-stratum weight of this source is at most p+3, even if it has many such targets. The buffer is strictly above those target segments, so the buffer units and the one-stratum units are distinct. For each source with positive one-stratum weight select its earliest such target; the entire buffer is already matched before that target. We do not charge the buffer again for any later one-stratum target. Different sources have distinct source-level units, even if their buffers overlap in deficit height or their time intervals overlap. A downward event cannot receive one level twice because causal matching is unique. Hence the following is a global charge without a factor for the number of prime labels or overlapping return intervals.

## 2. Expanded guard and branch reduction

Use a contiguous canonical block with pre-horizons in [X,Y], Y=lambda X, G=O_lambda(X), label cap C=floor sqrt(Y+1). Partition the actual list by pre-horizon bins of length L; assign every whole event to its bin. In bin j choose any subset of fast nonresets with labels T<=p<=R0<=C, T>=11, and k=floor sqrt(T), kw<g. Let F_j be selected gain, E_j the union of their guard intervals [d',d'+g], M_j its width. Let E_j have n_j connected components (zero for empty selection). Each component contains an entire selected interval of length >=T-1, so n_j<=M_j/(T-1). Expand each component [a,b] upwards to [a,b+2R0] and take the union Eplus_j. Then
    Mplus_j=length(Eplus_j)<=M_j+2R0*n_j
                          <=(1+2R0/(T-1))*M_j.         (1)
This expansion is chosen because the upper endpoint of B(p,h) is at distance <=2p<=2R0 above the ending deficit b of any one-stratum target with this p. The whole buffer lies in Eplus_j. In particular if R0=O(T), the expansion costs only a fixed factor in width, regardless of the number of selected events or absolute deficit baseline. No lower expansion is needed.

Perform the causal matching of ALL up/down transitions at each level of Eplus_j, inside this same bin. Its restriction to E_j is exactly the matching used before, since matching at a level does not depend on other levels. Retain a chosen upward source-label range [T,B1], where B1>=T (possibly >=C). The argument also permits an arbitrary fixed subset of actual sources; using a label range suffices here.

For the original selected downward population, write P_mid,j for its matched weight from these sources, decomposed into original cross-label O_j, one-stratum same-label S_j, and exceptional same-label X_j. From d422023, X_j<=10 times the number of actual upward sources of labels >=T, so sum X_j<=10G/(T-1). Now let C_j^cross denote ALL matched weight from these sources within Eplus_j to ANY actual downward target of distinct label (not necessarily fast or originally selected). Trivially C_j^cross>=O_j. By section 1 and (1), all buffers from the sources with positive S_j are present in this matching. Summing their separate charges, we also have
    C_j^cross >= ((T-3)/(T+3))*S_j.
We do not add O_j and the buffer bound: original cross-label matches can themselves contain buffer units. Combining the two inequalities correctly gives
    C_j^cross >= ((T-3)/(2T))*(O_j+S_j)
                = ((T-3)/(2T))*(P_mid,j-X_j).         (2)
This is the new branch reduction. Even if all the original nonexceptional selected matching were same-label one-stratum, a comparable amount of cross-label transport to other actual downward events is forced within the same bins. The cross-label targets can differ from the original chosen population; in particular they need not have fast clocks. This distinction is necessary. Both the chronological and height non-reuse are exact, including after the expansion, and the earlier source always precedes its matched target by pre-horizon difference <L.

## 3. Comparable-scale cross-label reduction, both endpoints with substantial drift

Use the preceding macroscopic short-bin regime, now with T>=11 tending to infinity,
    L=ceil(T(log T)^2), R0<=K0 T, M_j<=K0 T,
    F=sum_j F_j>=rho X, G_low=sum_{p<T}g=o(X),
where K0,rho>0 are fixed, T<=C, and lambda fixed. The number of nonempty bins is O_lambda(X/L), sum M_j=o(X). By (1) Mplus_j<=K2 T for a fixed K2 depending on K0. In particular sum Mplus_j=o(X). From the old causal matching theorem, for a sufficiently large fixed B1/T (choose B1=max(T,1+ceil(K0 T/delta1)) with small fixed delta1), the original middle-source weight satisfies
    sum_j P_mid,j >= rho X/2
for all sufficiently large windows. Recall the unmatched and low-source terms are o(X), and the source tail has bound sum M_j(1+L/(B1-1))=O_lambda(delta1 X)+o(X). This count is by pre-horizon span, so no requirement L>=C and no charge for a large overshooting last jump beyond the bin. Applying (2) and sum X_j=o(X) gives, for sufficiently large X,
    sum_j C_j^cross >= rho X/5.                        (3)
This reduction holds even if the original same-label branch dominates.

To restrict downward targets as well, the matched weight at any target is <=its actual ordinary drop, hence <=g. The sum for targets p<T is <=G_low=o(X). The weight at any single target in a bin is also <=Mplus_j; this follows from non-reuse at a target, regardless of how many source events contributed. Choose B2=max(T,1+ceil(K2 T/delta2)) with sufficiently small fixed delta2. For targets with label >B2, the bound on their count by pre-horizon span gives
    sum_j Mplus_j(1+L/(B2-1))=O_lambda(delta2 X)+o(X).
Choose delta2 small enough that this is <=rho X/40 eventually. No assumption on the selected source tail is used a second time. After deleting the low and large target weights, both labels belong to [T,K3 T], with fixed K3 (depending on lambda,K0,rho), and they are distinct.

Furthermore, for any fixed eta>0, the contribution to the remaining matching from sources with rise <eta*g or targets with drop <eta*g is at most eta G: sum actual rises and drops for these disjoint physical upward and downward events, each counted at most once in height units by the matching. Since G=O_lambda(X), choose eta sufficiently small that the bound is <=rho X/40. Thus, for all sufficiently large windows, a matched weight of at least rho X/8 survives with
    T<=p_source,p_target<=K3 T, p_source!=p_target,
    d'_source-d_source >=eta*(p_source-1),
    d_target-d'_target >=eta*(p_target-1),
    0<H_target-H_source<L,                            (4)
and both traversed segments meeting the same matched level of Eplus_j. These are actual causal source-target pairs. The selected population's own strong downward clocks are not inherited by the newly included targets; (4) gives a fixed positive relative downward movement, not kw<g. Each bin contributes at most L+B2 in remaining matched weight (sum of the gains of its retained downward targets, whose pre-horizons span <L and whose last gain is <=B2). Thus Omega(X/L) bins each have Omega(L) surviving weight. The short-bin source sieve from d422023 gives at least Omega((loglog T)^2) distinct source labels in each such bin. It does not give the same number of distinct target labels, since their waits may be short. This eliminates the need to handle a separate same-label-only recovery mechanism under the stated regime; it does not upper-bound the remaining cross-label supply by o(X).

## 4. Exact cross-label level/phase conditions

For a matched level u not at an endpoint, let the source label be p, side I, multiplier h, and the downward target label be r!=p, side J, multiplier k. Both labels >=T. Write a=2ph+6I, b=2rk+6J. Necessarily
    u<a<u+3p+1 (allow equality in the bound if using closed intervals),
    u-(r-3)<b<u
up to measure-zero endpoints. For each fixed u,p,I, there are at most two possible source multipliers, because the source interval has width 3p+1<4p. For each u,r,J there is at most one possible target multiplier, because its interval has width r-3<2r. This uses a continuous level rather than an approximate common ending deficit. The exact firing clock gives
    H_s = A mod 4p, A=e_I+p(2I-2h-1),
    H_t = D mod 4r, D=e_J+r(2J-2k-1),
from the parity of n=(H+p-1+d')/2. For delta=H_t-H_s>0 we must have D-delta-A=0 mod4. If compatible, there is one possible class modulo 4pr:
    H_s = A+4p z,
    z = ((D-delta-A)/4)*p^(-1) mod r.                  (5)
In particular for fixed level, labels, sides, allowed multiplier pair and horizon gap delta, at most one starting horizon in an interval of length 4pr is possible. For the recycling bins in (4), L<4T^2 eventually, so this is at most one per bin. We have not bounded the number of different compatible gaps or labels/levels sufficiently to derive a nontrivial aggregate cross-label upper bound from (5). The earlier upper sieve applies to source horizons, but (4) alone does not ensure long target waits. Counting both endpoints as rough would not be justified. The next target is a genuine supply bound for (4) using this phase condition and the intervening MIN constraints; the original small/middle crossing supply and general macroscopic upward population also remain open. No proof of twin infinitude or Lean kernel verification.
