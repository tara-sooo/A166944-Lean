## 2. NEW individual recorded history partition

For each endpoint M at a charged record S,lambda, its recorded pre-deficit at S is <lambda. If it has previously reached lambda in a recorded state, define D_M(lambda,S) to be its last actual recorded edge before S with d0>=lambda>d1. Such an edge exists since initial d=6<lambda. Otherwise call this endpoint virgin for that level. This is a recorded-history concept: a transient within a stationary wait that is lost by the outgoing jump is not counted as an earlier recorded attainment.

There are four disjoint pair types: both virgin; exactly one recycled; both recycled with distinct last-exit POST states; both recycled with same last-exit post state. A recycled endpoint's last exit ends no later than t_*. Indeed if its exit were strictly after the pair's first common recorded state, the common recorded history before S would contain a state >=lambda, contradicting first common record. If both last exit post states agree, that state is shared and is therefore precisely the common recorded birth (J_*,t_*). Their recorded predecessor states MUST differ; equal predecessors would give a common earlier >=lambda state. The two actual exit edges can have the same selected label with different recorded arrival times. No claim of distinct true physical states immediately before the final jump in that case.

For a fixed pair with common-exit poststate, the same two actual exit edges are fixed by the immediate recorded predecessors of the common birth. The number of levels in this type is at most min(delta_i,delta_j), where delta_i=d0_i-d1>0 and similarly j. All their charges summed are <=16 theta_ij min(delta_i,delta_j). This is a bound by the actual two pre-birth net descents, not a shared-recorded descent (the predecessors differ). It holds over all later first-record S and levels, since each pair/level has unique assignment. If one or both prior exits are distinct, they can be earlier than birth or one can end at birth. Earlier independent high histories cannot simply be counted as common positive energy.

## 3. NEW exact recorded merge tree and entropy capacity

Fix a physical record slot S. Take all source tags incident to any of its charged levels, freeze this set, size N_S. For each tag list its actual recorded states in reverse order beginning at the common start of S, down to its canonical root state. Form the trie of these sequences (a rooted tree whose common prefixes are identified). Add a distinct leaf for each original source at the end of its reversed sequence; this also handles a source beginning at an internal common recorded state. The root represents the start of S. All nodes are actual recorded states except the distinct source leaves. Every true common recorded state on two paths has the same deterministic subsequent recorded path to S, so is represented in their common trie prefix; conversely common prefix states are actual shared recorded states. Therefore the deepest common tree node of a pair, i.e. its LCA, is exactly its first common recorded state (J_*,t_*). Different immediate children correspond to different earlier recorded histories (or a canonical source leaf). This tree concerns recorded births, not first physical contact; two different recorded arrivals may already share physical ticks in their outgoing wait.

For each node V write n_V for its frozen descendant source count, including all levels at S, and for each child U write n_U. The sizes are positive and sum n_V. Fix lambda and use the actual pair-level edges at S only. Each pair edge is assigned to its LCA V and the two opposite children U,W. For every participating source i in U, create a constraint for its actual edges at this LCA directed toward W, of capacity
    c(i,V,W) = m0 n_W/n_V.
Use only constraints with at least one actual edge. For a fixed source at fixed S,lambda, its total capacity along all ancestors is bounded by
    m0 sum_(V on source path) (1-n_U/n_V)
       <= m0 sum log(n_V/n_U)
       = m0 log N_S.
This is telescoping, using 1-x<=-log x. It does not depend on the number of levels in the tree, number of branches, or repeated charges at distant merger nodes. The freeze is important: do not recalculate sizes after deletion. Total actual source/S/lambda memberships O(XB) from section1 and log N_S=O(log X)=O(u). Choose m0=u^7/4. Repeatedly pay all remaining incident pair-level weights of any constraint whose current degree is <=its capacity. Each constraint pays once, each edge at most once. Total absolute payment
    P_tree=O(XB m0 u)=O(XB u^11/4)=o(XBu^3).
All retained edges have both corresponding opposite-child degrees >their capacities, so for a surviving pair connecting U,W, its i endpoint has > (m0/432)n_W/n_V actual charged partners in that specific opposite child, and j has > (m0/432)n_U/n_V. These are actual distinct source partners at the same record and level with the same first common recorded birth, not all possible descendants. If n_V<=m0/432, every edge there is paid because even the maximal actual degree to W is <=432 n_W<=capacity. For balanced siblings n_U,n_W>=epsilon n_V with fixed epsilon>0, both endpoints of surviving edges have Omega(u^7/4) partners in the respective opposite earlier cohorts. This is much stronger than simply saying many tags eventually visit S. For very imbalanced siblings the smaller-side endpoint has strong opposite-cohort degree if the larger child is a fixed fraction of V, but the converse need not diverge. No general upper bound for remaining thick mergers. Earlier histories in different children are disjoint as recorded paths until V; they need not have disjoint true stationary ticks.

This absolute payment can follow earlier record-level or recycled quotas on disjoint remaining weights. If prior degree conditions are needed again after a fractional payment, re-peel with fixed capacities and explicit budget. The audit uses the entire unpeeled nonbirth record graph independently, not added to previous quotas. The entropy proof works also for a level-specific tree, but the common frozen tree for all levels avoids rebuilding and permits direct cross-level diagnostics; only that version is audited.
