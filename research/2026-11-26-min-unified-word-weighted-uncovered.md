## 3. Exact overlap cancellation

Under finite twins the original partition W_all<=W_B+int phi dW+o(NT) implies
    L_overlap=int [(1-alpha-phi)+alpha(1-chi)] dW=o(NT).   (2)
Every integrand nonnegative. Equivalently
    W_all-V_h <= int phi dmu - int chi(1-alpha-phi)dW+o(NT)
               <= int phi dmu+o(NT).                      (3)
Compared with XVI, the ENTIRE overlap int phi chi dW is removed from the upper, together with the covered unused fraction. This is a smaller combined upper at identical coefficients, not an assertion that actual forward charges themselves are confined to uncovered rows. They may occur on covered rows but reduce allowed backward weight. No addition of the previous missing-flow credits twice. Strict positive limsup L_overlap/(NT) on dyadic X suffices to contradict finite twins; or strict positive limsup int(1-phi)dmu/(NT). With admissible upper phi the latter can use one-tag reachability counts. Under finite twins int alpha dmu=o(NT) and int(1-phi)dmu=o(NT), so for fixed delta>0 missing clock with alpha>=delta or phi<=1-delta is o(NT). No uniform positive lower on either mass shown. In high sector alpha=a_v/n_c; in low sector alpha counts the full stable word, not one slot.

## 4. Quantitative word collision bound

On each original grid and strict source atom phase class (K,C,p,c), distribute actual event missing mass mu_i(e)=int_e(1-chi)dW_i over its original assigned atoms in same proportions as its wait. Since <=w_e, old row cap c_a P holds for total missing fraction at that atom. For word omega let M_omega be the missing CLOCK mass assigned to its stable focal tags. Thus M_omega<=c_a P a_omega and alpha_omega M_omega>=M_omega²/(c_a P n_c). Summing words/classes and averaging:
    int alpha dmu >= mean_P sum_atoms,classes,words M_omega²/(c_a P n_c). (4)
For classes with <=k stable words, sum_words M_omega²>=M_class²/k. Denote average missing assigned clock there M_{<=k}. Since sum P n_c<=N(H+P_max) per grid, Cauchy across the same averaged class measure yields
    int alpha dmu >= M_{<=k}²/[k c_a N(H+P_max)].          (5)
If fixed k and epsilon>0 and M_{<=k}>=epsilon NT infinitely often, (2) contradicted by positive margin asymptotically >=epsilon²/(3k) NT. Under finite twins M_{<=k}=o(NT) for every fixed k. Missing mass must use increasingly many DIFFERENT timed words and nearly fully forward-accessible partners. In high singleton regime many actual physical phases required. Old radical only bounds slots WITHIN a word, not number of words. Can use actual effective word number M_class²/sum M_omega² in (4). Unassigned missing paid by 1-alpha-phi; no claim of growing-k rate without quantitative errors. This yields a concrete sufficient concentration obstruction but no proof that such concentration is forced.
