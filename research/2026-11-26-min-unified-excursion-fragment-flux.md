# Integration XXVII: excursion-fragment guards and exact chronological height transport

2026-11-26 JST. Parent eb16cdf4b2377c1dbda40ced0aaea7463a5d2d7b; direct preflight [7b426da](https://github.com/tara-sooo/A166944-Lean/blob/7b426daaea1e966b1ee35414baa036e5ce3c6092/research/2026-11-26-min-direct-time-height-localized-upward-source-capacity.md). New: partition by actual returns to ordinary deficit <=6 as well as horizon bins. Only ONE fragment per bin can inherit positive guard potential, however many different guard sets occur in that bin. Exact level-by-level chronological matching prevents double use of upward flux, even across different guard choices. The resulting local source theorem needs a bound on individual excursion-fragment width, not on the sum or union of all their guards in a bin. It applies to actual original-tag core selections and retains the strengthened missing-clock budget. No final strict loss.

## 1. Fragment construction and exact matching

Use the original full stopped canonical tag paths with initial ordinary deficit 6, prehorizon C, gain g=p-1, w<=2p, d'=d+2w-g. Divide each actual tag path into excursions by cutting after every event with d'<=6 (include consecutive such events as single-event excursions). All excursions start with d<=6; except possibly terminal, end with d'<=6. This is a partition of complete physical events, not a partition by selected labels or interpolated gain. Adjusted resets in particular end at a cut. Independently partition prehorizons into half-open bins of length L, starting at C0 per tag, and intersect each bin's actual events with these excursions to form fragments. Every bin is a contiguous sequence of actual events, total gain <=L+B. Within a bin all but the first nonempty physical fragment start at d<=6. Terminal tails allowed. Each original tag has O(1+H/L) bins, even if stopping early. B<<L<=H in asymptotic application.

Choose ANY subset of actual fast high nonreset events with p>=Y, d'>6, k w<g, k=floor sqrt Y. May be exact XXI common-core events; do not truncate actual physical events at fragment edges. On each fragment Q make guard E_Q=union over selected events [d',d'+g], width m_Q, potential Phi_Q(d)=length(E_Q intersect [0,d]). Empty selection gives zero potential. For actual event in fragment, positive flux length E_Q intersect (d,d'] if d'>d, else zero. Every selected fast drop has entire interval (d',d] inside its guard, length g-2w>alpha g, alpha=1-2/k. Every event ending at d'<=6, in particular every reset, gives no positive flux. Let D_Q be exact selected drop length, P_Q all positive flux of its fragment, z_Q=Phi_Q(end), b_Q=Phi_Q(start). Then exact telescope gives
    alpha F_Q <= D_Q <= P_Q+b_Q-z_Q.                 (1)
For fresh excursion fragments b_Q=0 exactly, not a uniform guard-width upper. No cancellation between different potentials is assumed.

There is also exact chronological transport: for each real height a>6 not equal to a plateau deficit, upward crossings and downward crossings along a tag alternate, with the first crossing upward because initial deficit<=6. Match every downward crossing to its immediately preceding upward crossing, independently at each height. Every selected fast drop is matched at ALL heights in (d',d]. This gives a measurable transport (finite intervals; can equivalently use unit height intervals since deficits integral). The source occurs earlier on the SAME actual tag and SAME excursion, and each upward event-height pair is used at most once, even when guard sets of different fragments overlap. If the source lies outside the consumer's fragment, the matched height was already open at fragment entry, so the total such old matching mass O_Q<=b_Q. If the source is in the same fragment, its matched height belongs to E_Q, and its aggregate consumed mass <=P_Q. More precisely D_Q=O_Q+local matched mass; the latter is bounded by P_Q even if unselected downward events also consume resources. This construction does not allow a later source to pay an earlier fast drop, or a source on another tag to pay it. It is exact even if different fragments use different sets. The matching and potential inequalities are two views of the same budget, not additive.

## 2. Width cap on EACH fragment, not total guard width

Fix M_*>=0 (may depend on X), retain only fragments with m_Q<=M_* (or choose a subset giving this width before constructing guards). Set discarded fragments' selected list and potential to empty; every physical event remains available as a source only in its own fragment. Write F_j,D_j,P_j,Z_j,B_j^entry,O_j for sums of selected gain, actual drop, positive flux, terminal potential, entry potential, old matched mass in bin j of one original tag. Then
    alpha F_j+Z_j <= P_j+B_j^entry,
    O_j<=B_j^entry<=M_*.                            (2)
This follows because ONLY the first physical fragment can have nonzero entry, even if it is discarded. Total widths sum_Q m_Q in one bin may be arbitrarily larger than M_*; no cap on their union is imposed. In particular a bin with many short reset-separated excursions can repeatedly have independent local guards. A source event belongs to exactly one fragment and can supply at most min(M_*,3p+1) positive flux. Count actual events once, not once per target guard.

Let G_low,j count gain of actual nonreset sources with label p<Y in the bin (one may enlarge to ALL low nonreset gain). For a chosen source cutoff R>=Y, split P_j into low, middle Y<=p<=R, large p>R. Then
    P_low,j<=5 G_low,j,
    P_large,j<=M_* G_j/(R-1).                       (3)
If R>B there are no large sources. If selected population is a core subset, partition positive sources further into core vs omitted. All omitted positive flux is <=2 times actual omitted wait, since each actual event supplies at most (d'-d)_+<=2w. Equations (2)-(3) may use only core low/mid/large sources plus this omitted flux; no resets in any positive population. This is a direct improvement over paying total guard widths at every fragment, and over requiring a small single guard union per time bin as in direct 7b426da. The price is a condition on the selected fast population in EACH retained excursion-fragment, not automatic.

## 3. Transfer direct local source capacity to original lifetimes

Use direct 7b426da section1 with threshold Y->infinity, bin length L satisfying B Y^epsilon<=L<=H for fixed epsilon>0. At an actual positive source 2w>g, both C±1 avoid all odd f<g/4. Fixed p and side C=e+pq gives cofactor interval padded to ceil(L/p)+2, sieve cutoff floor(min(p,L/p)^(1/12)), error <=O(sqrt(L/p+2)); both q,pq+2e have distinct roots mod small odd primes. Thus number of actual positive events at fixed p in this bin <<_epsilon L/(p log²Y) (sum two sides). This is the direct translated-interval upper sieve on actual tag bins, with no full-X or repeated full-H penalty. The hypotheses are achievable, e.g. L=ceil(X^.7), 0<epsilon<.4, Y<=B. We use the same known sieve proof, not a new prime correlation estimate.

Let S_j be the DISTINCT actual middle source labels in the bin with positive flux in their OWN retained fragment (restrict core if used). Combining the occurrence bound with min(M_*,3p+1) per occurrence gives
    P_mid,j <<_epsilon L/log²Y * sum_{p in S_j} min(1,M_*/p).     (4)
Even if different excursions use completely unrelated height sets, a fixed source label is counted once per bin; each event belongs to just one fragment. This is the advantage of using a uniform cap per fragment rather than summing separate sieve errors for fragments (which could have length <<p). Exact individual width overlap may be kept for finer bounds; (4) uses only M_*.

## 4. Tagged local diversity and source scale with omitted clock

Let F=sum over original tags and bins F_j, N original roots. Assume along a sequence F>=rho NH, fixed rho>0, selected actual fast high nonresets from exact common cores, and M_*=o(L). Assume total actual core low NONRESET gain below Y is o(NH) and strengthened missing Mhat=o(NT). Do not assume total guard width (over fragments) is small. By XXII W_omit<=(1+o)Mhat+o(NT), hence total omitted positive flux o(NH). Sum entry potential <=M_* O(NH/L)=o(NH). Choose fixed delta>0 sufficiently small in rho, R=max(Y,1+ceil(M_*/delta)), so M_* /(R-1)<=delta. Large source flux <=delta NH since total actual gain<=NH. Summing (2)-(4):
    sum_j P_mid,j >= alpha F+sum_j Z_j
                    -5G_low,core-2 W_omit
                    -O(NH M_*/L)-delta NH
                 >= rho NH/2 + sum_j Z_j
for large X and small fixed delta. Consequently
    sum_{i,j} sum_{p in S_ij} min(1,M_*/p)
         >>_(rho,epsilon) (NH/L) log² Y.             (5)
In particular many local source incidences, with actual labels p<=O_rho(max(Y,M_*)), not necessarily the same labels as selected fast drops.

More explicitly at least c_rho NH/L TAG-BIN incidences have both F_j>=c_rho L and P_mid,j>=c_rho L, and weighted source diversity >> log²Y. Proof: number of bins<=c NH/L, and F_j<=G_j<=L+B<=2L. Take F_j>=rho L/(2c); their total F>=rho NH/2 and count>=rho NH/(4L). Outside o(NH/L) bins, each low core gain and omitted wait is below any fixed small multiple of L by their global little-o bounds. Entry<=M_*=o(L) uniformly; large flux<=2delta L. Choose delta sufficiently small in rho/c. Equations (2)-(4) then force stated local flux and diversity. At least c'_rho N original tags contain such bins, since each tag has O(H/L) bins. Incidences count original tags (possibly on the SAME physical common trajectory); no claim of that many distinct physical bins or independent source primes. No arbitrary cohort multiplier or per-core initial credit.

A practical sufficient width condition: if retained fragments have <=K distinct selected fast ending heights and selected labels<=P0, then m_Q<=K(P0-1); take M_*=KP0. If KP0=o(L), and the retained selected gain is macro, the theorem holds with sources p<=O_rho(KP0+Y). Unlike direct time-bin condition, K bounds heights PER excursion-fragment, not across the bin. Even a large total number of distinct ending heights over short reset-separated fragments is allowed. Another sufficient condition uses actual union width, no height count needed. No proof that macro fast gain lies in such fragments, that low nonreset gain is negligible, or that the source support has an upper below (5). If low nonreset gain is not negligible, it is an explicit alternative. The macro missing branch remains as before. This strengthens the conditional source theorem without providing the final constant gap.
