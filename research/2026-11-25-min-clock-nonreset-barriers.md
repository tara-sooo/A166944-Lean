## 2. Exact small deficit barriers

Every event satisfies d-d'<=p-3. If p=3 the deficit cannot decrease. For p>=5 and a nonreset, d'>=2p>=10. Thus d>=10 implies d'>=10 for a nonreset event. If a nonreset with p>=5 has d'<20, its only possibilities (p,s,k,d') are (5,0,1,10), (7,0,1,14), (5,1,1,16). In those cases d<=d'+p-3<=18. Hence d>=20 implies d'>=20 whenever the next event is not a reset. These barriers hold for arbitrary starting physical states satisfying the MIN conditions; they need not be canonical.

For integer 7<=P<=19 a nonreset selected q>=P leaves d'>=2q. If P=7 it stays >=10>P until a reset, by the first barrier. If P>=8, q>=11, hence d'>=22 and remains >=20>P until a reset. Thus a second selected p>=P from predeficit <=P without an intervening reset is impossible (even if the second event itself would reset). In particular the previous repeated-low-deficit-nonreset-launch class is empty in this entire threshold range, not just the finite experiments. The barrier proof does not cover P>=20.

If an original path has predeficit d<20, all events strictly since its last actual reset have labels <=7: a label >=11 would either be a later reset or would have raised d to >=22 with no descent below20 until another reset. By the LOW primorial barrier at 2*3*5*7=210, the gain from that last reset to the pre-horizon is <210. This is an actual recent-reset conclusion, regardless of how many previous canonical renewals occurred. At most 3 times this gain has elapsed (root or reset post-state is the start). It does not bound the basin of that last reset. In particular, small deficit is not a mechanism for an arbitrarily long reset-free suffix. The constant 20 barrier is not asserted to be the largest possible invariant region.

## 4. All-threshold original scan

At each selected event whose POST state is nonreset, let qmax be the maximum of all selected primes >=7 since the last actual reset STRICTLY BEFORE this event, or 0 if none. A repeated low-deficit launch exists at SOME integer P>=7 exactly iff
    min(qmax,p) >= max(7,d).
Indeed such a P must lie in [max(7,d),min(qmax,p)], and the latest earlier selected q>=P is nonreset and occurs since the last reset. The equivalence covers all thresholds simultaneously, not a finite sampling grid. Reset events clear qmax. This is a test identity, not a proof of its absence. Use prior qmax before updating with current p. The same qmax after update allows testing the stronger invariant above separately. Original cutoff fixed H, no restarting or extension.

## 5. New history-independent departure support

For p>=Y=max(17,ceil(B^1/8)), mark a selected event by either
    2d<=p-2, OR (post is nonreset and d<=p).
These conditions are on its actual predeficit, not on gain since a canonical point. In first case, nonnegative d' implies 2w>=p-1-d>=p/2, w>=p/4; in second case d'>=2p and d<=p imply w>=p. In both cases r(C)>=p/8. Moreover d'<=d+4p-(p-1)<=4p+1, so at most three nonnegative k values in the phase identity, and at most that many physical clock states per fixed predecessor C,p. Group original tags by labeled physical post key (J,v,p); each tag belongs once per key. This covers all nonreset low-deficit launches, even after long old excursions. It does not require any recent canonical point, and includes recorded crossing events with truncated waits.

For fixed p and sign, predecessor neighbors are pj,pj+-2, with odd j. The condition r(C)>=p/8 implies both j and pj+-2 avoid odd primes <=B^1/64 eventually. In variable (j-1)/2, each such odd prime excludes two distinct residues, as p is invertible. Apply the same uniform two-form Selberg upper sieve as in fdf6fe9/e15eb81: O(X/(p log² B)+B^3/32)=O(X/(p log² B)) predecessor horizons per label/sign, error absorbed by X/p>=cB. Counting the constant number of clock phases and summing p reciprocals yields O(X/u²) candidate keys, u=log B. Sum selected gains over distinct candidate keys is O(XB/u³) by Chebyshev bound for pi(B). This is the earlier proportional departure support scale but with a different, history-independent sufficient condition. The two departure classes need not contain one another; their union satisfies the same order of support via adding the two envelopes. Audit tests the new class and records events failing the earlier p>=10g+16 criterion, not the full union.

For m=floor(u^11/4), total actual selected gain at current thin keys with <=m original tags is O(XB/u^1/4). In any retained original family, repeatedly delete a root whose qualifying thin gain >=eps B, eps=u^-1/8, charging its actual currently thin keys. Each key is charged at most m times over the entire process, since memberships shrink and each charged root disappears. Thus delete O(X/u^1/8)=o(X) roots, with original late linear clock loss o(XB); each surviving root has <eps B qualifying thin gain. All other qualifying events have >m actual retained roots at their shared post key. This follows irrespective of whether repeated low-deficit launches exist in the canonical family. It is NOT an estimate of all large-deficit events, or of large group sizes. Keep natural MED and LOW destination accounting for event-only masks. A gain/clock bound does not itself bound the discarded quadratic energy.

## 7. Remaining

The local nonreset repeat exclusion is false in general, and even canonical trajectories violate the stronger maximum-prime deficit lower bound. Exact small barriers and a history-independent thin departure bound survive these counterexamples. The absence of repeated low-deficit launches for P>=20 among original paths is now a sharply specified canonical-reachability question, not a consequence of local phase congruences. A possible next approach is to examine the backwards reachable set of the synthetic example, or to derive a quantitative cost of the long negative-drift excursion before low-deficit high departure; the universal repeat exclusion is not needed if actual repeat contributions can instead be bounded. Interior high-deficit large-mass overlaps and both sufficient sector bounds remain open. Main untouched, Lean not compiled, twin-prime conjecture not proved.
