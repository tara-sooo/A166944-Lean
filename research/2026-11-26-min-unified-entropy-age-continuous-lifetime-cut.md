## 2. Global growth-weighted first-meeting age

Use the full original historical component forest from 96656af, where retired tags are retained in abstract membership but do not traverse further physical edges. For a vertex V with incoming historical component masses r_j and union historical mass R_V=sum_j r_j, each active incoming tag's historical size grows by ratio R_V/r_j. Along one original tag's own actual life, these ratios telescope, starting at 1 and ending at <=N. Thus
    sum_(V,j) sum_(i active in incoming j at V) log(R_V/r_j) <= N log N.  (1)
This is a sum of actual active incidences; historical retired members are not assigned an actual residence. If r_j<=R_V/2, each such incidence on a tag spends at least log 2 of this budget, so there are at most log_2 N of these per tag. Zero-growth unary vertices contribute nothing. This bound also holds for actual root injections and terminal meetings.

For every original unordered pair at its first actual meeting V=(t,C_V), choose its participant in the smaller of its TWO incoming historical components, ties by fixed original root order. Let r_ij be that component's mass. Then r_ij<=R_V/2, including when the two branches are not the largest at V. Define
    a_ij = eta H log(R_V/r_ij)/log N.
Pay all exact old surviving backward atom clock of this pair when K<C_V+a_ij. At an actual incoming membership (V,j,i) of the chosen kind, all partners assigned to i at one later source atom together have clock <=2 c_a P (both orientations, original denominator b). The path has at most a_ij/P+1 possible strict atoms with C_V<=K<C_V+a_ij. The age threshold is the same for all pairs assigned to this membership; it does not depend on the partner's identity. Sum over actual memberships with r_j<=R_V/2 and average original grids:
    B_young <= 2 c_a [ eta NH + P_max N log_2 N ] = o(NT).              (2)
Overlaps with old exact masks are paid only once. No sum over historical retired lifetimes or N^2 pair counts in this payment. This improves the OLD uniform birth age C_source-C_V>=D_s/2 with D_s=T/(u ell^6), at least in the K-C_V coordinate: every residual pair now has
    K-C_V>=a_ij>= eta H log 2/log N = Omega(H/(u ell^.25)).
Since K-C_source<P_max or <=B depending on crossing geometry (always <=B), the same order holds for C_source-C_V eventually. The guaranteed minimum grows by a factor of order ell^(23/4) relative to D_s, and the pair-dependent threshold can be much larger for asymmetric historical merges. The old maturity strip h may already be stronger for some attachment pairs, and all older age masks remain. No claim of a positive constant saving in total charge from this new little-o mask. This argument uses exact first meetings, not arbitrary meetings after coalescence.

## 3. Continuous crossing cohorts and fixed pair intervals

For every real K not a breakpoint, use all original completed crossing slots with pre/post horizons C<=K<J, full original b_G; one tag is in exactly one slot at K iff C0_i<=K<F_i. Thus the full cohorts partition actual crossing tags. A slot comprises all original tags executing the identical physical crossing; deterministic continuation means it cannot split into two different continuing cohorts as K increases, except for removals of terminated tags. At a projected arrival horizon C, process actual true states at that C in increasing t if needed. Root injections are singletons, retirements remove members, and distinct continuing cohorts can merge. Unchanged cohorts simply move to their next crossing slot. This description is a sweep of the original finite paths, not an extension of them.

Use ALL full crossing slots with b_G>=b0 as a relaxed source domain. This can be larger than the old P-specific positive-source set. For each such G let n=|G intersect eligible E_i at K| and a_j(V;G,K) be induced incoming counts on the actual eligible histories ending in G (as in 6bdfbed). Keep the original full denominator b_G. For every ordered pair (i,j) of distinct tags with an actual first meeting V, define a STATIC admissibility predicate: at least one ORIGINAL incoming branch mass >=L (and optionally any other already established source-independent pair predicate). For fixed such pair set
    I_ij = E_i intersect E_j intersect [C_V+a_ij, infinity).
One may intersect with the old fixed birth-age bound [C_V+D_s/2,infinity) as well. In the audit this latter is a finite proxy age. If no first meeting or static predicate fails, I_ij empty. Pair counts use actual first meeting only, not a new meeting based on induced branches. Induced condition is max(a_i,a_j)>=s at that original birth, where a_i,a_j denote the two actual incoming branches restricted to eligible tags. This is exactly the complement of the old induced both-small payment. Branch counts use all tagwise eligible tags, NOT just the pairwise admissible ones.

For grid comparison, intervals may be given half-open right-continuous endpoints at half-integers that preserve every integer K test: lower endpoint x replace by ceil(x)-1/2, upper inclusive endpoint y replace by floor(y)+1/2. This changes a continuous eligible strip length by at most O(1) per endpoint. Equivalently discard boundary equality contributions of size O(N P_max + N² P_max/b0) using the original caps. Use half-integer endpoints in the following definition so no isolated point exceptions. Define scalar step function
    f(K) = sum_(G:b_G>=b0) (1/b_G) sum_(ordered distinct i,j in G)
       1{K in I_ij} 1{max(a_i(V;G,K),a_j(V;G,K))>=s}.                (3)
Here the half-integer convention applies to E_i and I_ij only, physical crossing intervals [C,J) are unchanged. At integer K this agrees with the specified discrete tests. Keep all original eligibility domain restrictions; if a fixed old predicate is not used, (3) is a relaxation. The precise I_ij uses the chosen rounding in the integral; length bounds below allow O(1). This function is independent of P, though the exact old residual is not. It includes the actual original full cohort denominator, and excludes pairs already paid by these chosen masks. Define U_cont=integral_R f(K) dK.

For each pair, after its actual first meeting all its later shared crossings are deterministic. Let b_ij(K) be its full crossing-slot size where both actually cross K (undefined otherwise). By finite Fubini, (3) has the exact integral representation
    U_cont = sum_(ordered i!=j) integral_(I_ij)
       1{both cross K in same slot, b_ij(K)>=b0}
       1{max(a_i,a_j)>=s}/b_ij(K) dK.                             (4)
This is an equality for the relaxed scalar kernel, not the exact backward clock with its original masks and focal weights. For each term, its unrounded potential interval length is at most
    (H-h-|C0_i-C0_j|-a_ij)_+,
since C_V>=max(C0_i,C0_j), F_i<C0_i+H and F_j<C0_j+H. Rounded intervals add at most O(1). The two original prime origins must lie in the common lifetime window. More generally for any node V with n_V(K) induced eligible visitors at a source, all their roots lie in [K+h-H,C_V] up to endpoint convention, so the old uniform prime-interval upper sieve gives
    n_V(K) <= C [1+(C_V+H-h-K)_+/log(2+(C_V+H-h-K)_+)]
where use zero if the window is empty (and harmless O(1) endpoint adjustment for rounding). This retains the previous local branch quantile restriction and applies to all induced masses. Formula (4) makes both lifetime and root spread available in the same global weighted integral. Summing interval lengths with denominator merely b0 can be much too large; no contraction from this prime bound alone is asserted.

## 4. Global bounded variation lemma

For fixed s, b0, the total variation of (3) on R satisfies
    TV(f) <= C [ N(log(2+N)+b0+1+d s²/b0) + N²/b0 ].               (5)
The absolute C may absorb fixed pair endpoint counts; our static pair predicates and one interval per pair suffice. Proof by actual sweep, adding variations of the following operations. At simultaneous breakpoints process changes individually in any order consistent with actual cohort mergers, preserving true first-meeting branch labels; the net variation is at most the sum. Intermediates are used for the bound only.

(a) A cohort merge. Before merger with group sizes b1,b2, write numerator of (3) within each as q_i<=b_i². Counts at old first meetings of pairs within a previously separate cohort do not change due to other cohorts joining: if a new tag had visited one of those old true first-meeting vertices while those tags were present, it would already have been in their actual continuing cohort. At a multiway merge, newly created cross-pair contributions can be counted on combining branches while preserving their original branch labels; the relevant earlier vertices do not change, and counts in a given incoming branch of this actual vertex are fixed. Newly admitted ordered cross pairs number <=2 b1 b2. First use denominator max(b,b0), with no hard cutoff. The change in total normalized counts is O(min(b1,b2)): for b1<=b2, cross term <=2b1; small-side term <=b1; big-side term lost by denominator change <=b1 since denominator is 1-Lipschitz in b and q2<=b2². Now implement hard cutoff b>=b0. If both children below b0 and parent above, extra possible jump <=2b0. If one below cutoff and the other above, the omitted child term <=its mass; if both above, no extra. Thus an upper bound O(min(b1,b2)+b0) is valid for each genuine binary merge. At most N-1 such merges. Sum min(b1,b2) <= N log_2 N: use a historical component forest for this sweep (retirements retained as abstract membership); choose largest historical child and absorb remaining children in succession. The variation cost min(actual masses) is bounded by historical mass of an absorbed component, and each such component's members at least double their history mass (one can equivalently use union by size for binary steps). Each original member contributes at most log_2 N doublings. This handles multiway events by binary accounting while retaining actual original birth labels, not treating intermediate combinations as new births. No variation from merely proceeding to another slot if the cohort, eligibility, and age predicates do not change.

(b) A full-cohort insertion or retirement without merge changes b by 1. The numerator for eligible tags unchanged if first process eligible-member removal or last process its insertion. Denominator change contributes <=1 away from threshold, and crossing hard cutoff contributes O(b0); newborn singleton may be inserted as a new cohort. At most N insertions and N retirements. For retired members no past actual histories of surviving members are changed. Strips in fact exclude the tags at root and terminal.

(c) A single tag's eligibility endpoint in a cohort of size b>=b0. At most 2b ordered pairs involve the tag itself. For old pairs, the only changed induced branch tests can occur at a birth vertex on this tag's actual path where its incoming branch count crosses s. On insertion the old count in this branch is s-1. Among vertices where some OTHER eligible incoming branch is nonempty there is at most ONE such crossing: the induced count is nondecreasing along its path to the fixed source, and after this vertex the branch contains at least s even before insertion. Unary vertices cannot change any cross-pair predicate. At this vertex, changed pairs among old tags must have their other birth branch below s; the total such ordered count <=2(s-1)(d-1)(s-1)<=2ds². Deletion is the reverse operation. Fixed pair masks can only reduce the number changed. Divide by b, obtaining O(1+ds²/b0) per endpoint. Each tag has at most two eligibility endpoints (empty intervals omitted). For below-cutoff groups the function is zero. This proof specifically uses fixed s; varying s with b may change many old pair predicates and is not included in (5).

(d) Fixed pair interval age endpoint. After factoring out the tag eligibility endpoints in (c), each ordered pair has at most one additional lower endpoint from its first-meeting age test (or max of several static lower bounds). It changes the numerator by at most one, hence total variation from these <=N²/b0. At a pair endpoint, if its pair not present or another test fails the change is zero. Static yes/no birth masks do not vary. Additional arbitrary grid-dependent masks cannot be placed in (3) while invoking (5). These estimates prove (5) without assuming smoothness of actual trajectories.

For the parameters s<=eta b_min/d, b0=B^(1-o(1)), P_max<=B^.25, N/T=Theta(u^(-.75)), we obtain
    P_max TV(f) = o(NT).
Indeed ds²/b0 <= eta² b0/d, b0=O(B polylog B), N/b0=O(B polylog B), and P_max B polylog B /T ->0. No constant contraction inferred. The estimate also holds for the raw induced cut with the fixed pair age/static mask removed (drop the N²/b0 term).

## 5. Grid-free certificate and meaning of the new route

For any grid P, compactly supported right-continuous step function f satisfies
    |P sum_(K multiple P) f(K) - integral f(K)dK| <= P TV(f),
by comparing each sample to its integral over [K,K+P) and summing variations on these intervals. Thus all original grids simultaneously satisfy
    P sum_K f(K)=U_cont+o(NT)
uniformly. The exact original backward residual after (2), with previous masks and original positive-source domain, is <=c_a mean_P P sum_K f(K). We have
    B_new <= c_a U_cont + o(NT).
Forward unchanged. Under finitely many twins the old certificate becomes
    NT/2-o(NT) <= c_a U_cont+(3+o(1))(D_l,old+D_h,old).
A sufficient scalar route is therefore
    liminf (U_cont+D_l,old+D_h,old)/(NT) < 1/6.
Use the minimum of this bound and the old actual-positive-source induced cut U_ind, or other already valid exact capacities. On the same relaxed crossing-domain and identical strips, the additional static pair and age tests can only shrink the induced cut. But U_cont is NOT claimed to be uniformly below the previous U_ind, because U_ind only sums original P-specific positive source slots and (3) includes all b>=b0. The new age deletion (2) strictly strengthens the uniform necessary age condition regardless of this domain relaxation. The new integral eliminates grid-specific bookkeeping for this sufficient route and preserves simultaneous normalization and origin-pair lifetime support; no constant-margin bound on U_cont, old backward residual, or forward residual proved. Main and independent branches not modified. No Lean compilation.
