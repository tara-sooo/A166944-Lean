# Proof roadmap: first far projected contacts instead of suffix energy

2026-11-24 JST. Based on 0af34ea5078451d3687221b2aec8035f3db4142d, existing research/min-cycle-forest-2026-11-24. This is a paper-level roadmap with an elementary sufficient bound and a partial estimate, not a proof of the remaining bound or a Lean-checked theorem.

## 1. Freeze the main target

Canonical MIN, X dyadic, N=X/2 odd sources M in [X,2X), B=ceil(sqrt(7X)), initial horizon 2M-2, initial time M+2, original cutoff floor((7M-1)/4), LOW7 L=210. At every proposed high selected key (p,C), p>7, stop all tags if its active mass is >=T=ceil(B log^2 B), before execution. Keep the original source identities and cutoffs. The already derived S_key=O(XB/log^3 B) and low-block barrier imply R_pre=O(X^2/log B). Any unstopped non-twin terminal requires Omega(X) prefix cost, so there are o(X) such roots. Thus if there are no twin terminals in a window, the stopped population S is N-o(X). The two-tier scheme of the most recent note also works in the following contact reduction, as every stopped group has mass >= its lower threshold T; however, for estimating contacts choose the uniform cap first, so every executed parent key has mass <T.

Let d=floor(T/2). Define P_d as the number of ORDERED pairs of distinct original sources with |M-M'|>d that ever share a proposed high selected key, including a stopped key, in the uniform absorbed process. Count each pair ONCE, at its earliest shared high key; do not count shared suffixes, physical meetings, or repeated projected contacts again.

A stopped group of mass m>=T contains, for each of its members, at most 2 floor(d/2)<=d other roots at distance <=d, because the roots M are odd and spaced by two. Hence at least m(m-1-d) ordered far pairs are contained in that group. Stopped groups have disjoint original root sets, so their pairs cannot overlap. Therefore
    P_d >= sum_{stopped groups} m(m-1-d) >= (T-1-d) S.
If all terminals are non-twin then P_d >= (1/2-o(1)) N T. Conversely any fixed c<1/2 and unbounded dyadic windows with P_d<=c N T imply a positive fraction of unstopped roots, hence twins >=2X-3. In particular P_d=o(X B log^2 B) suffices. This is not an estimate on P_d itself. It avoids all costs of shared suffixes and counts each original pair just once. No physical coalescence assumption is used; projected groups can split and later rejoin.

## 2. The exact first-contact interface

For a proposed group G(p,C), partition its tags by their previous executed high key a=(q,D), or by singleton original roots with no previous high event. Every non-root class has D+q-1+g=C, with even 0<=g<L. Its size is <T in the uniform absorbed process. The previous key is the SAME for all arrival times in that class. Two tags meeting for the first time at G cannot belong to the same non-root predecessor class, because they would already have shared that earlier key. They must come from different classes, or involve initial roots. This remains true if different projected groups have previously split or rejoined.

Let A_a(p,C) denote the source set of a class and define the local far cross product
    J_d = sum_{(p,C)} sum_{a!=b} #{(M,M') in A_a(p,C) x A_b(p,C): |M-M'|>d}.
Then P_d<=J_d; equality need not hold because later repeated meetings may contribute. At sufficiently large B, two initial roots at the same C have distance <L/2<d, so their far pairs vanish. A sufficient (stronger) goal is J_d=o(NT), or liminf J_d/(NT)<1/2. If that is too strong because of repeated meetings, count the true first contacts P_d instead, using original source pairs or their first-contact certificates. Previous physical first-meeting formulas cannot simply be transplanted as equalities to projected keys.

For fixed (q,D),(q',D') and fixed g,g', the common target C is determined if consistent. The current p need not be counted independently: a pair of roots has at most one next high selected key at C, since C strictly increases along each trajectory. This permits using the earlier rough-predecessor pair sieve with no extra factor for p.

## 3. A provable partial removal at the pair level

Set a0=ceil(log^(1/4) B), Z=ceil(exp(sqrt(log B))). Consider ordered cross-class pairs where at least one non-root predecessor key is rough (r>=Z), and at least one of the two predecessor classes has size <=a0 at the current key. To apply the a0 factor across different current p at the same C, impose the size <=a0 condition on the WHOLE earlier executed predecessor group, not on the current subclass; for an initial root class use the bounded number A=floor(L/4)+1 of possible initial roots at C. For distinct predecessor labels q,q', the CRT and two-form sieve in min-projected-rough-saturation.md, section 4, bounds the total candidate tuples (q,q',g,g',C) with a rough predecessor by O(X(log log B)^2/log B). For same q but distinct previous keys (different g), use the single-prime rough count O(X log log B/log B); for an initial root paired with rough predecessor the same count suffices with O_L(1) root choices. For each candidate previous-key pair, the sum of cross products over current p is at most the product of the two whole parent masses, <=a0 T, since the source subsets are disjoint as p varies. For initial roots the product is <=A T. Consequently the contribution of these pairs to J_d, without even requiring far separation or first contact, is
    O((a0+A) T X (log log B)^2/log B) = o(NT).
This is a valid partial removal, not a bound on all rough contacts: two already concentrated predecessors can have product almost T^2. The unweighted rough-transition count alone is too weak for them. Likewise nonrough predecessors are not covered. A first far pair necessarily includes an earlier root whose gain by C exceeds 2d, so the previous shallow-ancestry geometric bound identifies a long-ancestry tag in each remaining pair.

## 4. Work sequence and completion criteria

1. Implement exact first-projected-contact diagnostic on moderate windows, with uniform cap T, plus deliberately lower caps such as B/4 and B/2 to expose nonempty stopped groups. Record P_d and J_d separately, the ratio P_d/(NT), the contribution of repeated projected contacts, and verify P_d >= (T-1-d) S. Do not infer asymptotics from windows where T is larger than observed group masses.
2. Partition J_d or P_d by the two original predecessor masses (dyadic), their label sizes, r(D), r(D'), and root separation. Measure which portions involve two already concentrated predecessors, and which are cheap/cheap. For any pair with an initial root, keep it as a separate class; all root tags retain original cutoff. The partial theorem above removes small-parent/rough-parent contacts asymptotically. The main proof obligation is the complement.
3. Use exact cutoff-tagged reverse-clock recursion to bound the remaining cross product, not the unweighted number of eligible predecessor keys. A concrete target on each predecessor label/roughness/mass class is an average bound for the products of separated original-root masses, summed over admissible (q,D),(q',D'),C. If using a dyadic partition, ensure the summed bound is o(NT), or a fixed constant strictly below (1/2)NT along an unbounded sequence. Do not require an unnecessarily uniform pointwise bound W(C)<=T. An alternative if the product overcount is severe is the exact first-contact count by excluding earlier common high keys. The small-parent sieve has a linear loss in a0; replacing it with T is not a solution.
4. If a proof of the aggregate bound succeeds, the elementary stopped-group inequality above gives S <= (1-epsilon)N. Since unstopped non-twin roots number o(X), for each sufficiently large window on the subsequence at least one genuine twin terminal exists, with its smaller prime >=2X-3. This proves infinitude. The prior two-tier scheme remains an alternative, but its increased caps alone do not bound S.
5. Independently audit the analytic sieve hypotheses, the canonical finite reduction, and implement a Lean formalization of the stopped-source and first-contact inequalities. Then integrate a proved analytic estimate (not an assumed axiom) and the unbounded-window implication. Check final theorem axioms and CI.
