## 1. Exact residence area, without a new initial budget

Retain XXVII original complete paths, excursion fragments Q in prehorizon bins of length L, guard E_Q of selected fast high nonreset events, width <=M_*; discard wide fragments' selection, not their physical events. Ordinary deficit starts <=6 at every fresh excursion. Each selected fast consumer t has actual downward height interval (d'_t,d_t], length g_t-2w_t>alpha g_t. Use the exact last-up matching at every height >6 from XXVII. A local match has source s and consumer t in the SAME retained fragment, s<t. Denote its total matched length by m_st (zero if no such match). Nonlocal/old matches from earlier fragments are NOT in this matrix. Old total <=O(NH M_*/L) as in XXVII (B<<L<=H). Every positive source can supply at most min(M_*,3p_s+1) in aggregate, and m_st<=g_t. Only actual matched flux is counted, not all positive guard flux.

For a local pair define actual intervening gain and wait
    E_st=C_t-J_s=sum_(s<j<t) g_j,
    U_st=t_arrival,t-n_s=sum_(s<j<t) w_j.
Both are zero for consecutive physical events. At pre-event state j strictly between s,t, a matched height is still above its most recent up-crossing and has not yet been down-crossed. Equivalently it is in E_Q intersect [0,d_j], and the open height intervals of all such local pairs are disjoint at that pre-state, up to endpoints. Otherwise two different source-consumer arcs would use the same upward crossing or have an intervening downward crossing at that height, contrary to last-up matching. Let I_j be their total open length. Thus 0<=I_j<=Phi_Q(d_j)<=M_*.
Finite exchange of sums gives EXACT identities
    sum_(s,t local in Q) m_st E_st = sum_(j in Q) g_j I_j,
    sum_(s,t local in Q) m_st U_st = sum_(j in Q) w_j I_j.    (1)
Consequently sum m_st E_st<=sum_Q sum_j g_j Phi_Q(d_j)<=M_* G_all and similarly sum m_st U_st<=M_* W_all. This holds even if the sum of fragment widths in one bin is arbitrarily large, because each event belongs to exactly one fragment. No additional entry credit, and no source on another tag. Also E_st and U_st are *intervening*, not source or consumer event lengths. For any A>0, matched local mass with E_st>A M_* is <=NH/A, with U_st>A M_* <=3NH/A, since G_all<=NH,W_all<=3NH. More generally use exact area instead of uniform cap; if M_*=0 then selected gain zero. This is a quantitative concentration of actual consumption within O(M_*) of its source (in both coordinates). No bound on every individual pair or on absolute deficit follows. Replacing E_st by pre-to-pre distance costs the actual source gain, so only for bounded source scale p_s=O(M_*) is that distance also O(M_*).

On the small-missing branch of XXII, choose core consumers and retain only middle core sources Y<=p<=R=max(Y,1+ceil(M_*/delta)) with delta fixed small. For F>=rho NH selected fast gain, M_*=o(L), core low nonreset gain o(NH), Mhat=o(NT), discard old, omitted-source (<=2W_omit), low and large source mass using XXVII's upper budgets. Then actual LOCAL matched middle-source mass M_mid>=alpha F-o(NH)-delta NH>=rho NH/2 for small delta. This is stronger in interpretation than a lower bound on total positive flux: the sources actually supply the chosen consumers. By (1), for any fixed tolerance tau>0 all but tau NH of this mass have E_st,U_st<=A M_* for A chosen sufficiently large in tau. These deductions use no support upper.

## 2. Joint short-relay CRT capacity

In a given actual original tag-bin restrict to local matched middle sources p in [Y,R0], selected consumers r in [Y,P0], with R0,P0<=B (and may bound them by guard width and middle cutoff). Let S be actual source labels carrying such matched mass and Cset actual consumer labels, c=|Cset|; D_s=sum_(p in S)min(1,M_*/p). Fix integer K with 0<=K<Y-1. Any matched pair with E_st<=K has p!=r: same-label horizons differ by 2mp+e2-e1, m>=1 (odd cofactors strictly increase), so E_st>=p-1. For distinct labels at fixed E,sides e1,e2, source prehorizon C obeys
    C=e1 mod p, C+p-1+E=e2 mod r.
Thus one CRT progression mod pr in the actual prehorizon bin. Each candidate C specifies at most one source event and one consumer event at its fixed horizon. The source is genuinely upward, so both source neighbors avoid odd primes f<(p-1)/4. On C=C_*+pr z, source cofactor q=q_*+r z and opposite neighbor pq+2e1 have distinct forbidden roots for odd f<Y. Apply the earlier translated 2D Selberg bound with padded interval length ceil(L/(pr))+2 and cutoff floor(min(Y,L/(pr))^(1/12)), bounded cases by trivial count; if needed reduce cutoff by fixed factor to stay below (Y-1)/4. Error absorbed by padded length/log². Consequently number of pairs at fixed tuple is
    << (1+L/(pr))/Lambda²,
    Lambda=log(2+min(Y,L/(R0 P0))).
Uniform in actual sides and K. No roughness assumption on the fast CONSUMER, which would be false in general. This counts necessary candidates, not independent source/consumer events. In particular one must not use a four-form roughness gain on this pair merely because both labels are high.

Weight each pair by m_st<=4 min(M_*,p,r). Since 1+L/(pr)<=(L+R0 P0)/(pr), and min(M_*,p,r)/(pr)<=min(1,M_*/p)/r, summing the four sides, all E<=K and actual supports gives
    M_short,j(K) << (K+1)(L+R0 P0) D_s c/(Y Lambda²).      (2)
One can keep sum_(r in Cset)1/r instead of c/Y. This is joint matched supply; does not sum individual source capacities again. Use local supports AFTER restricting to the chosen consumer-source pairs, or enlarge to all middle sources and all selected fast consumers in the bin. If a tag-bin has no selected matches, its contribution zero. No arbitrary physical multiplicity; sum over original tags. Unsieved count valid with Lambda replaced by 1, useful at top scale L/(R0P0) small.

For a concrete aggregate implication suppose polynomial Y->infty, R0P0<=L/Y^epsilon0 with fixed epsilon0>0, and sum D_s<=D0 (NH/L) log²Y, with c<=C_* on the bins retained in the estimate (C_* may grow). Then (2) sums to
    M_short(K) <<_(epsilon0,D0) NH (K+1) C_*/Y.           (3)
If these bins carry M_mid>=rho0 NH and C_*=o(Y), choose K=floor(c0 Y/C_*) with a sufficiently small fixed c0>0 depending on rho0 and constants (and ensure K<Y-1). Then short mass <=rho0 NH/2 for large X; at least rho0 NH/2 is supplied across intervening gain E_st>K. In particular if K fixed and C_*=o(Y), immediate/ bounded relay matched supply is o(NH). This is a necessary lower separation for sparse consumer support, not a universal bound on total matched mass. Combining (1) and (3) forces moment >=const NH Y/C_* on these bins, so one cannot use a hypothetical smaller residence area than this. The width cap alone does not contradict it: every nonempty guard with label>=Y has width>=Y-1. The hypothesis R0P0<=L/Y^epsilon0 can hold at lower scales, not automatically at top labels for the D=X^.7 bins. No assumption of near-minimal support or sparse consumers is forced by XXVII.

## 3. Transfer averaged same-label return sieve to consumed weights

Use direct cb54101 sections 1-4, threshold Y, L>=B Y^epsilon, R0<=const Y^b (fixed b) as well as <=B. In each original tag-bin take the actual list of distinct local middle upward sources s with positive total MATCHED mass a_s=sum_t m_st, after any chosen consumer selection (may restrict further by E,U, etc). Then 0<a_s<=4 min(M_*,p_s) from section1. List visits of a given p in chronological order, across all excursion-fragments of the bin, regardless of distinct guard sets. No separate error per fragment. Odd q=(C-e)/p strictly increases; consecutive gap q2-q1=2m. Both endpoints rough; the four forms q,q+2m,pq+2e1,p(q+2m)+2e2 have generic four distinct roots except primes dividing
    m(pm+e2)(pm-e1)(pm+e2-e1).
Direct's uniform average over 1<=m<=K, (log Y)^a<=K<=Y^d0, removes the worst loglog singular factor. Use exactly its bound #pairs per label << L K/(p log^4Y), not a new sieve proof. It applies to all actual source pairs and hence to consecutive pairs of this restricted matched list. Each source occurrence is counted once with a_s, independent of how many consumers it supplies. Denote D_s as in section2 with these matched supports. The matched mass associated with a preceding SHORT same-label gap m<=K is
    M_prev,short(K) << L K D_s/log^4Y.
The first matched source per label costs <=4R0 D_s. The mass associated with a preceding LONG gap m>K is << L D_s/(K+1), by exact span sum <=(L+2)/(2p). Crucially the identical bounds hold for FOLLOWING gaps, with LAST instead of FIRST, by charging each pair's STARTING matched mass instead of ending mass, both bounded by same label-dependent cap. No equality between the two weighted distributions is asserted.

Sum over actual tag-bins. If M_mid>=rho0 NH and sum D_s<=D0 (NH/L) log²Y, fixed positive rho0,D0, the first+last mass is o(NH) (R0<=B<=L/Y^epsilon). For any fixed tolerance tau>0 choose a0>0 small and b0>a0 large (constants depending on tau, rho0,D0,epsilon,b), K1=floor(a0 log²Y), K2=ceil(b0 log²Y). By direct averaged four-form bound and span bound, all but tau M_mid of the matched mass has BOTH a preceding and a following source of the same label in its bin, each with
    a0 log²Y < m <= b0 log²Y+1.                         (4)
Use union bound on the four tails and first/last; no independence. This is not a constraint on all actual upward occurrences, only on the selected matched-source list. If there are more source labels, direct's near-minimal support hypothesis can fail. If old/omitted source flux or wide fragments dominate, section1 does not force M_mid macro.

## 4. Two distinct physical scales

Under the preceding macro and near-minimal hypotheses, further assume M_*=o(Y log²Y). Since a consumer label>=Y implies M_*>=Y-1 on nonempty fragments, the meaningful range includes M_*=O(Y) or slow logarithmic enlargement. Combine (1),(4) with fixed tolerance: all but arbitrarily small fixed fraction of actual middle matched mass is carried by pairs for which E_st,U_st<=A M_*, while the source s has both neighboring same-label matched sources separated in prehorizon by at least 2a0 p_s log²Y-2. The source gain p_s-1<=R0=O(M_*+Y) if using the middle cutoff of XXVII. Thus the matched consumer prehorizon is strictly before the next same-label matched source, and lies in a window of length O(M_*) after source prehorizon. Windows of these good sources of one label in one bin are disjoint for large X: for any two consecutive good sources their gap is at least the following-gap lower bound of the first (even with intervening bad sources). This is an actual separation between consumption and recycling of the same prime, not a claim that all return intervals are free of other labels. Equation (2) may further exclude very short intervening gaps if consumer support is sparse. Together the constraints localize the arithmetic problem to matched short-scale source-consumer neighborhoods inside much longer same-label return intervals. There is no upper bound below macro on the number or supply of those neighborhoods; they may be numerous and other labels can interleave. No final contradiction.
